# Exact tetragonal point group 4/mmm (D4h): scope and integration

## Attribution and claim boundary

The crystallographic class 4/mmm is the established Hermann–Mauguin
notation for Schoenflies D4h (ditetragonal dipyramidal class), not
a novel classification. The source screenshot is a visual description,
not experimental proof of the specimen's internal atomic structure.

The computational witness lives in
`scripts/tetragonal_d4h_exact_certificate.py`. It enumerates the
16 distinct integral orthogonal matrices from quarter-turn R, vertical
mirror S, and horizontal mirror H; tests relations, closure,
inversion R²H=-I, determinants, twofold rotation axes, mirror
planes, and finite-sample invariant values.

The finite test of invariants is **not** a proof that the invariant
ring is generated by x²+y², x²y², z². The full ring theorem needs
an independent algebraic derivation or kernel proof.

## Algebra

R = [[0,-1,0],[1,0,0],[0,0,1]]
S = diag(1,-1,1)
H = diag(1,1,-1)

R^4=S²=H²=I; SRS=R^-1; HR=RH; HS=SH.

Every matrix has the form R^a S^b H^c, where
a in Z/4Z and b,c in Z/2Z. This gives D4 × C2,
abstractly isomorphic to the crystallographic point group D4h.

The five order-two proper rotations with trace -1 include the vertical
R² axis and four horizontal axes. Five reflection matrices with
trace +1 include H and four vertical reflection planes.
The fourfold rotoinversion is (-I)R.

Next formal owners should encode Fin 4 × Bool × Bool with dihedral
multiplication (a,b,c)*(d,e,f)=(a+(-1)^b d,b xor e,c xor f),
prove the homomorphism to GL(3,Z), prove injectivity by normal forms,
and reuse the native group-action framework. Establish the invariant
ring theorem using generators and invariant polynomial reductions.
Only after this should lattice actions / Seitz pairs be introduced.
