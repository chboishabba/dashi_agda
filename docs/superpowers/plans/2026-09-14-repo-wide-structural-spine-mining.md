# Repo-Wide Structural Spine Mining

**Goal:** Apply the same extraction modality used for coarse/fine and RSA-derived execution machinery to arbitrary DASHI lanes: mine repeated structural moves, reuse an existing canonical owner when one exists, add an exact crosswalk when multiple equivalent carriers already exist, and create a new Core carrier only after multiple independent manifestations justify it.

## Method

For every apparently random lane-local construction:

```text
manifestation
-> identify consumer
-> identify exact carrier/obligation
-> search existing Core/Interop owners
-> classify relationship
   SAME CARRIER       -> direct reuse / alias / thin adapter
   EQUIVALENT CARRIER -> prove bidirectional crosswalk
   STRICT REFINEMENT  -> preserve richer carrier, expose projection to parent
   ANALOGY ONLY        -> no theorem transport
   MISSING STRUCTURE   -> explicit unpaid seam
-> migrate real consumers
-> retain provenance/status/source roles
-> only then consider deprecating duplicate local machinery
```

Canonical promotion requires typed factorisation or exact translation, not lexical similarity.

## Mining priority function

Rank a proposed extraction roughly by:

```text
(number of real consumers unlocked)
* (independent domains)
* (duplicate machinery removed)
* (open payments clarified)
* (future theorem reuse)
/
(new abstraction complexity + migration risk)
```

Prefer exact crosswalks over new carriers when equivalent machinery already exists.

## Non-collapse rule

The programme is not "everything is secretly the same thing." It is:

```text
same theorem shape -> crosswalk/reuse
strictly richer theorem -> parent projection + retained extra structure
shared analogy only -> provenance note, no transport
incompatible obligations -> keep separate
```
