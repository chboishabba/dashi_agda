# Digital-ESD Political Economy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved political-economy, social-provisioning, institutional-durability and intersectional challenge seam without creating a parallel evidence, intersectionality, community or proof-search ontology.

**Architecture:** Reuse the existing `ComparativeInstitutionalMeaningExact`, `DigitalESDExternalityIncidenceAuditExact`, `DigitalESDDisabilityIntersectionalityAuditExact`, `DigitalESDStudyIntersectionalAbsenceAuditExact`, `CommunityConnectednessTopologyExact`, open-commons/lifecycle and source-attribution owners. New Digital-ESD owners add only education-specific composition and bounded source fixtures. Search protocol changes are versioned as v2 rather than rewriting frozen v1 history.

**Tech Stack:** Agda exact owners, existing DASHI `FactorsThrough` / nonfactorability machinery, `AttributedSourceCore`, GitHub source-level regression/import surfaces.

**Spec:** `docs/superpowers/specs/2026-09-17-digital-esd-political-economy-sustainability-design.md`

## Global Constraints

- Preserve transcript provenance != DASHI synthesis != external empirical/theoretical source evidence.
- Exact source identity, DOI/URL, role, population/object, design, time, scope and claim ceiling remain attached.
- Political-economy label alone must not manufacture a waste, learning, sustainability or causal claim.
- Existing intersectional/disability and study-level absence audits are mandatory consumers for every new political-economy/provisioning/durability bridge.
- Do not duplicate generic intersectionality, community-connectedness, comparative-institutional, externality, lifecycle, open-commons or proof-search machinery.
- Do not mutate frozen search v1 as if new concepts were present historically; add a versioned v2 amendment.
- No Agda/kernel or CI certification claim without an observed receipt.
