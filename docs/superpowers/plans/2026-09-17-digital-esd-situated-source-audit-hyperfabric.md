# Digital-ESD Situated Source Audit Hyperfabric Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every Digital-ESD synthesis source carry a provenance-preserving, observer-indexed 0–5 visibility audit with sparse intersections, standards lenses, admissibility and preserved tensions.

**Architecture:** Build thin Education-domain composition owners over canonical `AttributedSourceCore`, snowball provenance, `IntersectionalNonFactorability`, Two-Eyed Seeing/Kimmerer, and existing Digital-ESD audit owners. The 0–5 score is only a projection; admission consumes richer situated observations and never computes an authoritative grand total.

**Tech Stack:** Agda; repository-local source attribution and regression patterns; GitHub source-order TDD in this connector-only session.

**Spec:** `docs/superpowers/specs/2026-09-17-digital-esd-situated-source-audit-hyperfabric-design.md`

## Global Constraints

- External source proposition != DASHI reconstruction != DASHI theorem.
- DOI/PMID/PMCID/PDB/taxon/QID/Dewey are identity/classification coordinates only; unresolved identifiers are never guessed.
- Source role and claim ceiling remain orthogonal to score.
- Score measures visibility/coverage only; no authoritative grand total exists.
- Two-Eyed Seeing/Kimmerer are source-bounded coordination donors; coordination != fusion and shared observation != shared provenance.
- Standards/framework sources are normative/process lenses; conformance != empirical educational effect.
- Sparse intersections are added only from actual source study, consumer requirement, or a constructive `FactorsThrough` collision.
- Source-written != Agda/kernel certified; no GREEN claim without an exact-head execution receipt.
- Current-master/PR-only Ibrahim/PNF/Pareto improvements are not silently imported into this stale branch.
