# Lombardi Australian Colonial Finance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved Lombardi / Montefiore-Rothschild / Maralinga-Pine Gap provenance tranche as a thin, attribution-safe extension of DASHI's existing genealogy, Pine Gap, Epstein-style source-atlas, and consumer-observer machinery.

**Architecture:** Reuse `EvidenceGradedGenealogyCore` as the evidence spine, consume the existing Pine Gap and Australia-US sovereignty owners directly, mirror the Epstein branch's claim-local source semantics, and add only case-specific relation refinements plus a Lombardi coarse-observer adapter. The implementation terminates in a source-bounded max-cut receipt whose remaining work is concrete archival acquisition rather than more generic graph machinery.

**Tech Stack:** Agda, existing DASHI Core/Governance/Physics owners, static source-regression checks where available, GitHub branch `agent/lombardi-australian-colonial-finance-maxcut-20261017`.

**Spec:** `docs/superpowers/specs/2026-10-17-lombardi-australian-colonial-finance-design.md`

## Global Constraints

- Reuse `DASHI.Governance.EvidenceGradedGenealogyCore`; do not create a competing evidence calculus.
- Reuse `DASHI.Physics.Foundations.IndigenousMilitaryIntelligenceCircuitExact`; do not redefine Pine Gap, Arrernte Country, or its existing negative receipts.
- Reuse `DASHI.Governance.AustraliaUSAllianceSovereigntyGenealogyExact` for sovereignty/dependence semantics.
- Mirror the Epstein source-atlas distinction between source identity, source role, bounded claim, and promotion ceiling.
- Keep religion/ethnicity non-causal: Jewish identity must never pay coordination, command, motive, culpability, or financial-network continuity.
- Mark Lombardi artwork as representation authority only; underlying historical edges need independent source receipts.
- `sharedStrategicLandGrammar` must not imply `programmeLineage`.
- `graphPath`, visual adjacency, node degree, visual centrality, and shared counterparty must not self-promote to causal/command claims.
- Do not claim exact-head Agda kernel-green status unless actually executed; CI is not the max-cut.

## Review Focus

- Family/kinship edges accidentally promoting into business agency or coordination.
- Artwork-derived BCCI edges accidentally gaining the authority of the Senate historical record.
- Maralinga/Pine Gap shared abstraction accidentally manufacturing programme lineage or a specific targeting chain.
- Coarse diagram projection accidentally becoming injective, losing the required fine-state collision witness.
- Source-role/status metadata accidentally being treated as truth, transaction settlement, wrongdoing, or culpability.
