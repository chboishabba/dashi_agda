# Nongin max-cut completion design

## Scope

Complete the Nongin programme as Nongin, using the current `master` theorem graph as the authority surface and keeping later LILA/E8/Monster/teleodynamic/exceptional-group programmes downstream rather than prerequisites.

The implementation is intentionally split into four cuts:

1. consumer-relative 1.0 -> 1.1 informational advantage;
2. recursive observer/depth/reopening tower;
3. current-master Nongin capstone and provenance-safe descendant wiring;
4. full relational-site vs 6/12/8 boundary-nerve comparison, stopping at the first genuinely missing same-object/coherence theorem.

A certified higher stack / hypersheaf is explicitly outside the Nongin completion criterion. Existing higher-descent owners remain reusable downstream.

## Design constraints

- Preserve the raw Nongin source as historical/generative provenance only.
- Do not reinterpret `+10% / 1.1` as a literal quantitative or empirical advantage law.
- Do not retroactively attribute trialectic, 369, Grothendieck, p-adic, E8, Monster, Albert/F4, LILA, or teleodynamic theorems to the raw source.
- Reuse canonical `FactorsThrough`, consumer-descent, dependent-reopening, depth, Grothendieck, trialectic, and Čech owners rather than create parallel machinery.
- Prefer theorem-bearing finite witnesses over Boolean boundary flags.
- Keep selected-corner-star promotion distinct from full 6/12/8 boundary-nerve equivalence.
- Keep the irreducible trialectic face distinct from an ordinary Čech triple intersection.
- No kernel/typecheck claim without an observed exact-head compiler receipt.

## A. Consumer-relative 1.0 -> 1.1 theorem

### Goal

Replace the historical rhetorical reading of `1.0 -> 1.1` with the exact consumer-relative statement:

```text
coarse observer pi : Fine -> Coarse
consumer C : Fine -> Output
x != y
pi x = pi y
C x != C y
--------------------------------
C does not factor through pi
```

An enriched observer that retains the missing distinction may then be shown sufficient for that declared consumer.

### Proposed owner

`DASHI/Philosophy/NonginConsumerRelativePowerUpExact.agda`

### Reuse

- `DASHI.Core.ConsumerDescentMinimalObserverExact`
- canonical `FactorsThrough` / non-descent witnesses
- `DASHI.Core.ConsumerFibreRepairExact` if its interfaces match the current need
- `DASHI.Philosophy.ReflexivePowerUp`
- `DASHI.Philosophy.NonginOriginFormalizationExact`

### Required theorems

1. Generic collision-to-nonfactorability compiler.
2. Generic enriched-observer repair theorem for a supplied separating coordinate.
3. Concrete Nongin debate fixture: the public binary frame collapses two fine debate states that a declared consumer distinguishes.
4. A frame-bearing/reflexive enriched observer that preserves the lower representation and restores the declared distinction.
5. Firewall:
   `consumer-relative distinction advantage != universal outcome advantage != literal 10% law`.

### Success criterion

The repository can state the central Nongin intuition as:

> a representation is strictly more adequate for a declared consumer when it separates a consumer-relevant fibre collision that the coarser representation cannot separate.

No numerical advantage factor is introduced.

## B. Recursive observer / depth / reopening tower

### Goal

Replace the current purely syntactic `ObserverTerm` nesting with a concrete depth-indexed observation tower whose truncations can lose distinctions and whose dependent residual can reopen the fine state.

### Proposed owner

`DASHI/Philosophy/NonginRecursiveObserverDepthTowerExact.agda`

### Reuse

- `DASHI.Foundations.TrialecticDepthHyperformExact`
- `DASHI.Foundations.RelationalDepthPresheafExact`
- `DASHI.Foundations.RelationalDepthBidescentExact`
- `DASHI.Core.DependentRecoverableProjectionExact`
- existing recursive fibre/inverse-limit owners where the carrier interfaces genuinely align
- `NonginOriginFormalizationExact.ObserverTerm`

### Required structure

For depth `d`:

```text
FineState d
observe/truncate : FineState (suc d) -> FineState d
residual : dependent information lost by truncation
reopen : coarse + residual -> fine
```

The tower must expose:

- identity at fixed depth;
- compositional truncation across multiple depths;
- at least one explicit collision at a coarser depth;
- exact dependent reopening for the selected collision family;
- a bridge from nested `ObserverTerm` depth to the typed depth index without claiming every arbitrary observer term has trialectic semantics.

### Success criterion

The source intuition

```text
O(x), O(O(x)), O1(O2(O1(x))), ...
```

has an exact repository descendant:

```text
fine state
 -> depth-indexed observations
 -> possible coarse collision
 + dependent residual
 -> exact reopen.
```

## D. Full relational-site vs 6/12/8 boundary-nerve max-cut

### Goal

Push beyond the currently paid selected corner-star comparison to the strongest exact same-object comparison available between the relational trialectic cover and the full Base369 6-face / 12-edge / 8-corner boundary nerve.

### First archaeology targets

- `Trialectic369CechModelSameObjectCapstoneExact`
- `Trialectic369CechAugmentedCornerStarIndexExact`
- `Trialectic369CechCornerStarRecognitionExact`
- `Trialectic369AppraisalSharedX6SliceExact`
- `ActualFaceHypercubeGluingFromSharedSliceExact`
- existing full face/edge/corner indexing and Hasse-incidence owners
- relational Grothendieck `RelObj` / `RelHom` owners
- any generic nerve, Hasse, face-lattice, cubical, or simplicial incidence owner already on master

### Required distinction

Do not force the relational irreducible face to become an ordinary triple overlap. The comparison should distinguish at least:

```text
relational cover nerve / dyadic overlaps
attached irreducible trialectic 2-cell
augmented selected tripleABC index
full cube boundary face/edge/corner incidence
```

### Preferred endpoint

Construct explicit maps between the relational/augmented index and the full boundary index, then prove as much of the following as the existing carriers permit:

1. stratum map preserves dimension/role;
2. incidence/Hasse order preservation;
3. selected-corner-star retraction/section consistency;
4. coverage of all 6 faces / 12 edges / 8 corners;
5. two-sided same-object index recovery if possible;
6. action/naturality compatibility with participant `C3` and existing chart actions if those are already typed on both sides.

If two-sided recovery fails, the stopping theorem must identify the exact missing stratum/action/coherence witness rather than add another abstract boundary flag.

### Success criterion

Either:

```text
full relational/augmented trialectic boundary nerve ~= full Base369 6/12/8 boundary nerve
```

with explicit same-object/incidence receipts,

or one irreducible theorem statement pinning the precise missing map/coherence datum.

## Testing and verification

Implementation must follow RED-first/TDD where practical:

- add focused validation/regression owner before each new production owner;
- use existing finite witnesses and `refl`/constructor equalities as local regression checks;
- add the new owners to the narrowest existing trialectic/Nongin rollup rather than broad unrelated aggregates;
- inspect exact-head GitHub Actions receipts if present;
- if no exact-head Agda run is observable, report source-written/static-integrated only.

Do not repair unrelated master-wide compiler failures unless they directly block these owners and the fix is itself small and semantically necessary.

## Explicit non-goals

- full higher-stack / hypersheaf certification;
- E8/Monster/Albert/F4 same-object recognition;
- LILA or teleodynamic empirical realization;
- a universal decision-theoretic benefit from richer representations;
- a psychological or social-scientific 10% performance claim;
- rewriting existing provenance ownership.

## Completion definition

Nongin is considered complete at this max-cut when A, B, and C are implemented and D has either paid the full boundary-nerve comparison or reduced it to one explicit irreducible missing same-object/coherence theorem.

The higher-stack/hypersheaf programme remains a separate optional continuation after this completion boundary.
