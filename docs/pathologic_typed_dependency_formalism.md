# Pathologic, typed dependencies, RSI hyperedges and marked unit extension

This tranche adds four connected formal layers while keeping game criticism,
mathematics, psychoanalytic interpretation and empirical claims in separate
authority lanes.

## From inhabitation to dependency

An inhabited action constructor says only that an action belongs to the action
type. It does not establish that the action is currently available, prudent,
morally permitted or narratively required.

The new dependency core therefore indexes evidence by source and target, and
indexes Pathologic actions by the current state:

```text
ActionDependency state action
  = time witness
  × health witness
  × reputation witness
  × role capability
  × provenance receipt
```

The same pattern upgrades Boolean gluing, memory-preservation, stage and RSI
surfaces without deleting their existing Boolean projections.

## Pathologic constraint field

The Pathologic layer distinguishes:

- action existence from admissibility;
- admissibility from prudence;
- prudence from moral permission;
- authored negative affordance from implementation defect;
- character knowledge from cross-run player knowledge;
- local route evidence from a view from nowhere.

The day-two economy has an exact tenfold shock witness, but the formalisation
does not reduce the game to a scalar optimisation problem.

## Perspective hyperfabric

Bachelor, Haruspex and Changeling are represented as local epistemic sections.
Incidence with a world question requires a route-indexed evidence constructor.
The three endings preserve and destroy different typed targets, so their
comparison is represented as a no-typed-meet until an additional value judgment
is supplied.

The independent twelve-day lens maps prologue/day 1/.../day 12 to Stage
0/1/.../12 by index only. This does not identify game-day semantics with the
repository's stage interpretations.

## Theatre and metafiction

The theatre layer records nested dependencies among developers, game system,
player, avatar, executors, children and the Powers That Be. Player agency and
game counter-agency coexist:

```text
player controls avatar
system constrains player
developers author system
```

The final provenance reveal changes what the player knows about construction.
It does not erase the causal and affective trace of the enacted run.

## RSI and sinthome

RSI is upgraded from a three-Boolean conjunction to:

- deletion-sensitive logical dependence;
- an irreducible ternary support witness;
- one typed RSI hyperedge with a compatible section.

Topological Borromeanity remains open.

The sinthome is path-indexed and proof-bearing. An admissible stabiliser must
supply witnesses for coherence after stabilisation, residual retention, memory
preservation and non-equivalence to erasure. Minimality requires a separately
declared cost model.

## Marked unit extension

The j+1 refinement treats the user's `j-previous subfibre` as a compound label,
not subtraction. The exact common law is:

```text
carrier + marked unit = extended carrier
```

with two instances:

```text
10j + j = 11j
196883 + 1 = 196884
```

The stage unit is a labelled fresh subfibre-scale unit. The moonshine unit is an
independently supplied trivial one-dimensional component. No internal
196882-dimensional subrepresentation is asserted, and the carriers, scales and
semantics are not identified.
