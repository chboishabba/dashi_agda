## 1. Highest-value original NOAA lead: OBS-TIME and original month forms

[NOAA original by_station 8-column dictionary](https://www.ncei.noaa.gov/pub/data/ghcn/daily/readme-by_station.txt) explicitly defines the 8th CSV field OBS-TIME as HHMM, **blank if no observation time is available**, populated from the [original NOAA HOMR historical-station database](https://www.ncei.noaa.gov/access/homr/api). [NOAA by_year dictionary](https://www.ncei.noaa.gov/pub/data/ghcn/daily/by_year/readme-by_year.txt) confirms the same field. This is a *first-party format source* **P1-73**, not a newly retrieved July 1953 station-clock value. HOMR original documentation **P1-74** supports date-scoped station history via qualified IDs GHCND:USW00014606 / GHCND:USC00170371. The original HOMR 1953 date-specific endpoint was attempted but not accessible in browsing; never assert a 1953 value based on an API template alone.

[NOAA/NCEI first-party Cooperative Observer Network](https://www.ncei.noaa.gov/products/land-based-station/cooperative-observer-network) original publication **P1-75** states that it retains **original handwritten monthly observer forms**, sometimes containing notes omitted from daily digital summaries, and separately provides routes to hourly/15-minute original precipitation observations **at a subset of stations**. This locates a materially more original 1953 source class; no exact July 1953 sheet for either gauge has been inspected. No assertion that the specific stations have these higher-frequency data.

**Acquisition ceiling:** the [original 1953 annual GHCNd CSV gzip](https://www.ncei.noaa.gov/pub/data/ghcn/daily/by_year/1953.csv.gz) is publicly indexed (~110MB compressed) but raw CSV bytes could not be retrieved through this web/tool environment. ## 2. Explicit temporal-bucket hypothesis: an actual finite partition, not historical time series

The existing 269-character .dly reports **Bangor July 6/7/8: 66,193,46; Bar Harbor 3 NW: 0,130,0**, all in tenths-mm. These are two geographic **station streams under a single NOAA archival custodian**. They do not report rainfall onset at Reich's Ellsworth/Graham Lake site.

Consider a strictly *hypothetical* event at the **same station local** clock on 6 July at 22:00, and make an additional right-closed local-24h-accumulation assumption for the date-labelled daily buckets. Let c be the observation cutoff in local minutes since midnight and t=1320 (22:00). The reported date label is **6 July if c ≥ 1320**, and **7 July if c < 1320**. Across all 1,440 possible minute cutoffs there are exactly **120 possibilities for July 6** (22:00–23:59 inclusive) and **1,320 for July 7** (00:00–21:59). Boundary convention is explicit. If the actual observation-time field is blank, both outcomes remain admissible; it is a mistake to impute midnight. Even if c is known at *Bar Harbor*, its gauge location differs from the 1953 alleged Ellsworth site, and hour-specific rainfall is still not reconstructed by a nonzero day-total.

This is source-written and self-testable in [OBS-TIME and bucket checker](../../scripts/check_psychotronics_1953_observation_clock.py), with [eight adverse format/gzip/provenance regressions](../../tests/test_psychotronics_1953_observation_clock.py). Case-specific original-format source join validates exact 1953 dates, station IDs, PRCP tenths-mm values, quality flags and optional HHMM, rejects duplicate/contradictory rows, and supports NOAA by_year single file or separate by_station gzip/plain inputs. Accepting a locally hashed file does **not** authenticate NOAA original publisher custody. **No 1953 OBS-TIME has been supplied or inferred in this cut**.
