## Interpretation rule

The matrix separates **what a source can legitimately contribute** from what remains unpaid for a downstream consumer. In particular:

- acquisition is not inclusion;
- institutional authority within a source’s domain is not intervention-effect evidence;
- a method standard specifies coordinates but does not supply the corresponding deployment measurement;
- normative interoperability or open-system guidance does not prove persistence in a deployed platform;
- participant/public-governance guidance does not create local constitutive epistemic authority; and
- programme activity, technology adoption and task performance remain distinct from system transformation and learning.

The matrix is therefore intended to survive into structured extraction as provenance/context metadata if and only if the corresponding sources are admitted through the completed search and screening lineage.
