### Pareto front (not a scalar rank)

Axes are **temporal grain / original measured-data accessibility / independent cohort / rights / direct consumer closure / model separation**. Consumer utility statements are DASHI judgments, NOT published quantitative utilities.

* **A — Niedernhuber primary neural transition:** highest apparent immediate *public-data/software* leverage, a distinct 25-person controlled cohort, and original observed transition metrics. Must inspect Zenodo file/rights/review and GitHub code identity first. Valid consumer: EEG transition model versus within-subject treatment controls. Invalid transfer: EEG microstates→hallucination narratives, or Markov predictability→external agents.
* **B — Sanders primary experiential phases:** closest published source to onset of **perceived presence** and multisensory/3D precursors. Needs the original 21 matrices, 125-category codebook, missingness and same-cohort subject crosswalk. Article figures give descriptive trajectories but are not raw matrices. Especially valuable for restricted phenomenological M1a.
* **C — Lewis-Healey time-resolved EEG/TET:** independent original dose-responsive neural/experience time series with measurements at better time grain than retrospective narratives. Dataset must be requested; TET ratings should not be invented as agent or geometric-motif labels.
* **D — Erowid source-controlled narrative timing:** large number of reports but underlying paper's category distribution does not identify transitions, and raw corpus access/AI processing need written Erowid Center permission. More generic toy cycles are dominated by source/governance acquisition.
* **E — Timmermann/Sawicka/DMT_NCT original-source chain:** neural time dynamics already studied and some derivative code/data openly advertised. Benefit: source-aligned intensity/control signatures. Precise source cohort, processing and original static reproduction remain separate obligations. **Do not count branches of the same author cohort as independent replication.**
* **F — Prospective M1a/M2 discrimination and concealed-target channel:** possibly transformative but impossible to claim from any above data. Requires a pre-registered observable restriction, matched model capacity, controlled information leakage and separate ethics/consent.

**Ibrahim dependency join:** compute root identities first, then follow citations/code/data to the actual *measurement object*; distinguish parent study, secondary analysis, independently recruited participants, executable analysis and literary citation. Sanders→Timmermann shares specified protocol provenance while exact participant identity remains unknown; Sawicka/Timmermann and DMT_NCT need exact source-dependent lineage receipts. Niedernhuber is a different trial/intervention design; do not pool it with IV DMT as if same exposure. Erowid narrative reports are neither measured neuronal transitions nor matched people. Snowball stops when another paper merely repeats the same root instead of yielding a new object, method or incompatible prediction.
