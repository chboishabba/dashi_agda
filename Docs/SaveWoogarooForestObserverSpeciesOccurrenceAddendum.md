## Purpose

This addendum records observer-supplied FrogID/iNaturalist occurrence evidence as a separate Snowball evidence fibre. It must not be collapsed into proponent ecology, expert validation, agency findings or statutory conclusions.

```text

```

## Current bounded legal significance

Queensland's current environmental-offset material classifies *Adelotus brevis* / Tusked Frog as NCA class V (Vulnerable). If capture 948283 is later expert-validated, the observer-confirmed coordinate can then be joined against the exact Opossum/Woogaroo creek, SHG landscape, project and corridor geometries.

That still does not by itself establish:

```text
species occurrence
-> critical habitat
-> significant detrimental effect
-> EPBC controlled matter
-> injunction / refusal
```

Each legal consumer requires its own statutory and factual coordinates.
