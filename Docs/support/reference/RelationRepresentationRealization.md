# Relation Representation, Dynamic Adequacy, and Realization

## Purpose

This tranche formalizes the bridge from semantic/embedding relation codes to downstream consumer use without assuming that a fixed latent direction is the primitive.

The architecture is:

```text
matched / situated pair
-> representation family
-> comparison geometry
-> task-relative factorization
-> future-safe trace commutation
-> residual reopening
-> explicit target-domain realization witness
-> authority boundary
```

The new modules deliberately reuse existing owners for compression, non-factorability, PNF future-safe dynamics, grokking, capability/functioning, and phase/amplitude separation.

## Core distinction

A successful relation code can be useful without being a complete relation realization.

```text
encoding != dynamic adequacy != realization != normative authority
```

`RelationRepresentationAdequacyExact` therefore types the following transformation families separately:

- fixed translation;
- linear rotation;
- affine transformation;
- learned nonlinear transformation;
- quotient compression;
- manifold-constrained transformation;
- application-supplied transformation.

It also separates the comparison geometry:

- cosine-like;
- ordinal-concordance;
- magnitude-aware;
- calibrated monotone;
- Riemannian/geodesic;
- application-supplied.

The same representation family can therefore be evaluated under different comparison geometries without identifying either with semantic interpretation.

## Dynamic adequacy

The future-safe theorem surface delegates to:

```text
DASHI.Cognition.PNF.DynamicMultiQueryMultiResolutionExact
```

A current representation is not future-safe merely because it predicts the present task. The compressed global carrier and local residual must commute with every declared query/action step. The existing arbitrary-trace theorem then yields consumer preservation over the complete declared trace.

This is cross-checked against the merged grokking owner:

```text
DASHI.Cognition.PNF.LLMGrokkingLearningFutureExact
```

which already proves that equal present training/current generalization observations can hide different learning futures.

## Realization obligation

`RelationRepresentationRealizationExact` introduces only the missing seam:

```text
RepresentationRealizationWitness
```

A target-domain realization requires an application-supplied decoder and exact commuting receipt:

```text
targetPhenomenon fine = realize (encode fine)
```

Static adequacy, dynamic adequacy, or geometric fit cannot manufacture this witness automatically. A single representation collision that separates the target phenomenon rules out every realization decoder through that code.

This is structurally analogous to the TSFV realization boundary: a constructed history/action representation and a constructed target object do not justify arbitrary carrier identification.

## Eigenslur / flourishing adapter

`EigenslurFlourishingRelationBoundaryExact` keeps the motivating experiment thin.

For eigenslur-style work the schema is:

```text
contextualized derogatory epithet
vs
matched target-identity baseline
```

For flourishing/virtue-style work the schema is:

```text
candidate improved / virtuous action-state
vs
matched neutral or baseline action-state
inside the same declared situation
```

The adapter does not force either experiment into a fixed translation. Rotation, affine, nonlinear, quotient, and manifold-constrained candidates remain admissible.

The finite ethical regression constructs a coarse positive code that is exactly sufficient for a coarse valence task but collapses an agency distinction. Therefore positive/beneficial-looking outcome compression is not sufficient for a richer flourishing consumer.

The existing Sen-calibrated owner is reused directly:

```text
DASHI.Governance.CapabilityFunctioningNonDescentExact
```

so realized functioning still does not recover capability.

## Phase/operator precedent

The regression keeps the existing finite cyclotomic phase/amplitude owner live:

```text
DASHI.Biology.CyclotomicPhaseAmplitudeBoundaryExact
```

It proves both same-phase/different-amplitude and same-amplitude/different-phase witnesses. This is the relevant repo precedent for keeping rotation/phase/operator structure separate from magnitude and from semantic interpretation; no continuous `sin/cos/tan` ontology is manufactured from a finite phase carrier.

## Source registry

`RelationRepresentationSourceRegistryExact` records author, title, venue, year, identifier, bounded imported role, and excluded promotion.

### Miranda Anna Christ; Adrián Csiszárik; Gergely Becsó; Dániel Varga

**The Structure of Relation Decoding Linear Operators in Large Language Models**. Advances in Neural Information Processing Systems 38 (NeurIPS 2025), Spotlight. DOI `10.52202/085713-1438`; arXiv `2510.26543`.

Imported role: relation-decoder collections can be highly compressed and appear property-centric under cross-evaluation. Excluded promotion: compressed operator = complete semantic relation.

### Michael Freenor; Lauren Alvarez

**Steering Embedding Models with Geometric Rotation: Mapping Semantic Relationships Across Languages and Models**. arXiv preprint (2025). DOI `10.48550/arXiv.2510.09790`.

Imported role: rotational semantic transformations can transfer across languages/models in the reported experiments. Excluded promotion: universal semantic rotation ontology.

### Daniel Wurgaft et al.

**Manifold Steering Reveals the Shared Geometry of Neural Network Representation and Behavior**. arXiv preprint (2026). DOI `10.48550/arXiv.2605.05115`.

Imported role: manifold-respecting steering can better follow natural behavior geometry than flat linear steering. Excluded promotion: fitted activation manifold = semantic or ethical ontology.

### Xinbo Ai

**Beyond Cosine Similarity**. arXiv preprint (2026). DOI `10.48550/arXiv.2602.05266`.

Imported role: recos provides an ordinal-concordance alternative to cosine and reports improved STS correlation across eleven embedding models. Excluded promotion: metric benchmark success = semantic realization or consumer sufficiency.

### Ravi Dhiman; Andrea Passarella; Mirco Tribastone; Lorenzo Valerio

**Neural Network Compression by Approximate Differential Equivalence**. arXiv preprint (2026). DOI `10.48550/arXiv.2606.01402`.

Imported role: functional/dynamical equivalence can be used as a compression primitive. Excluded promotion: approximate differential equivalence = complete semantic identity.

### Hari K Prakash; Charles H Martin

**Late-Stage Generalization Collapse in Grokking: Detecting anti-grokking with Weightwatcher**. arXiv preprint (2026). DOI `10.48550/arXiv.2602.02859`.

Imported role: a previously successful generalizing checkpoint can later collapse, motivating future-sensitive adequacy. Excluded promotion: one spectral diagnostic = universal mechanism.

### Eigenslur editorial essay

**Eigenslur, Defined**. eigenslur.com, 13 July 2026. No DOI asserted; individual author is not asserted on the cited page.

Imported role: conceptual residual/dominant-component formulation and the explicit admission that `eigen-` properly suggests an operator. The essay's `contempt is low-rank; craft is full-rank` language remains source rhetoric/hypothesis, not a theorem in DASHI.

## Claim boundary

rotation -> universal semantic transform
manifold fit -> semantic essence
current fit -> future safety

positive valence -> flourishing
flourishing -> rank one
