# Future residuals, finite Cantor mass, and restricted metastability — Round 14

This tranche continues the future-equivalence programme from Round 13.  It does not add another generic quotient shell; it closes three concrete theorem gaps left by the frontier list.

## 1. Residuals over the canonical future quotient

`DASHI.Core.FutureQuotientResidualExact` separates the canonical future-safe quotient from the extra receipt required for later reopening.

For a concrete `FutureEquivalencePresentation`, an `ExactResidualOverFutureQuotient` supplies

`delta : X -> D`

and

`R : Q x D -> X`

with exact reopening

`R(classOf x, delta x) = x`.

The theorem `classAndResidualDetermineState` proves that the quotient class plus residual is injective: if two states have the same future class and the same residual, then the fine states are equal.

A weaker `RelevantResidualOverFutureQuotient` only requires reopening to a state in the same canonical future-equivalence class.  `exactResidualIsRelevant` proves exact reopening implies future-relevant reopening.

This makes the optimization target precise: the canonical future quotient answers what may be forgotten permanently; residual optimization answers how cheaply one can still reopen a representative when an application needs more than future-equivalence.

## 2. Restricted-reachability metastability

`DASHI.Cognition.PNF.RestrictedConstraintMetastabilityExact` strengthens the global C3 frustration result.

The underlying triangle still requires

- `A = B`,
- `B = C`,
- `A = next(C)`,

so its global minimum indicator frustration is 1.

A restricted local update graph is then declared in which only phase A may advance.  The assignment `(0,1,2)` has cost 2; its only one-step successor has the same cost, so it is a one-step local minimum.  Because B and C are invariants of every restricted path, the global cost-1 witness `(0,0,0)` is unreachable.

Thus the module gives an exact finite witness of a non-global persistent basin generated by reachability restrictions rather than by the bare energy function.

## 3. Finite Cantor cylinder mass at arbitrary depth

`DASHI.Foundations.CantorCylinderMassExact` generalizes the earlier depth-three `27 ambient / 8 polar` reference.

A polar cylinder at depth `d` is assigned the dyadic representation

`1 / 2^d`.

The module retains numerator and denominator separately rather than importing analytic measure theory.  At each refinement:

- the child denominator is twice the parent denominator;
- one parent is replaced by two numerator-one children;
- at the common child denominator, parent numerator 2 equals child numerator sum 2.

At every finite depth, the polar cylinder count is exactly `2^d`, equal to the common denominator.  Therefore the complete polar layer has normalized total mass one at every finite depth.

This is a finite cylinder premeasure/conservation spine.  It is not the sigma-additive extension theorem, does not prove `lambda(C)=0` for the limiting Cantor set, and does not prove the Hausdorff-dimension formula.

## 4. Current semantic equality versus future-safe equality

`DASHI.Cognition.PNF.SpokenTelescopeFutureEquivalenceExact` instantiates the canonical future-language relation on the existing sentence

> I saw John with the telescope.

The instrumental and possession parses still have the same bounded answer to `who was seen?`, but under the continuation trace that asks who had the telescope, the instrumental parse admits `holder=speaker` whereas the possession parse cannot.

Therefore current bounded consumer equality does not imply canonical future equivalence.  This is the semantic counterpart of the hidden-phase dynamic insufficiency theorem.

## Boundary

The cumulative result is now:

**future equivalence identifies exactly the distinctions that no admissible consumer-visible continuation can expose; an exact residual refines a future-equivalence class back to a representative; finite Cantor refinement conserves normalized intrinsic mass; and restricted transition geometry can trap a system above its global frustration minimum.**

No claim is made here of a universal minimal-description theorem over arbitrary residual spaces, a sigma-additive limiting Cantor measure construction, or a universal metastability theorem for arbitrary hyperfabrics.
