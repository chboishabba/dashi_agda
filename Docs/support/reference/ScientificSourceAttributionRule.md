# Scientific source attribution rule

For every external scientific source represented in DASHI source, receipts, docs, or experiment metadata, record at minimum:

1. **Author or consortium**
2. **Title**
3. **DOI or other stable identifier**

If no DOI exists, use the strongest available stable identifier, such as PMID/PMCID, arXiv or bioRxiv identifier, dataset accession/version, standards identifier, court/report identifier, or another stable archival identifier appropriate to the source.

A bare URL is not a sufficient canonical attribution when a stable identifier exists. URLs may be included as convenience locators in addition to, not instead of, stable attribution.

For source updates or journal versions that supersede a preprint, preserve version/provenance distinctions rather than silently replacing one evidential object with another.

This is an attribution/provenance rule; it does not by itself promote the scientific claims carried by a source.
