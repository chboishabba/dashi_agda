# Base369 relational update kernel — Round 8

This tranche promotes the attached relational analysis into typed Agda structures while preserving the boundary between exact carrier results and still-open semantic or empirical claims.

## Interaction and appraisal

The primitive event is an ordered interaction cube:

```text
A position x B position x calculated outcome
```

with 27 states.  The immediate outcome then supports a six-coordinate appraisal fibre:

```text
A: feeling, preference, synthesis stance
B: feeling, preference, synthesis stance
```

with 729 states.  One complete round therefore has nine ternary coordinates and 19,683 raw states:

```text
27 interaction states x 729 appraisal states = 19,683.
```

Event occurrence and participant assent are retained as independent coordinates.  No map from an occurred event to joint agreement is supplied.

## Pointed appraisal decomposition

The exact identity

```text
729 = 8 * 90 + 9
```

is represented by a pointed address carrier:

```text
8 noncentral positions x 10 fine sectors x 9 secondary positions
+ 1 shared central 9-sheet.
```

This supplies a concrete form of the proposed noncentral-versus-centre architecture.  It is an address theorem, not a claim that every psychological or Monster-theoretic interpretation is canonical.

## Calculation fibre and closure

A nine-sheet is represented as an ordered binary relational operator with a ternary result.  Its full result carries origin, proposal, path, output proof and open boundaries.  A vanishing point is typed relative to an idempotent closure operator.

The interface carriers distinguish:

```text
9 + 1 = orientation/witness
9 + 2 = source-target distinction
9 + 3 = complete new ternary axis
10 x 9 = 90 relational slots
90 + 9 = established surface plus an unintegrated sheet
```

These are interface and address counts, not total state-space dimensions.

## Proposition-indexed actual response

A response is indexed by:

```text
participant
exact guarded proposition node
decision episode
time
```

The proposition node carries context, contemplated action, factored modality and scope.  Modality is separated into deliberative, selection and obligational axes.

`mightConsider` is represented by existence of at least one history in which the option is weighed.  The record deliberately does not contain universal weighing, selection, execution or menu-closure fields.

Transport across descendant nodes, context, modality, scope and time requires five independent witnesses.  Thus positive response to `Consider z` is not positive response to `Commit z`.

Valid consent additionally requires a counterfactual choice cone, sufficient capacity and participant-produced provenance.

## Shared-state weave

A valid weave preserves:

```text
participant contribution
participant-specific appraisal
outcome/agreement distinction
decision provenance
open boundaries
repair state
absence of unsupported downstream carry
```

Pseudo-consultation is typed as an interface that solicits an input without a causal-sensitivity witness.  Object displacement marks the interrupted fibre `displacedUnrepaired` rather than silently completing it.

Cessation and repair use separate completion states:

```text
no active conflict + uninstantiated = stopped without repair
no active conflict + instantiated   = completed repair
```

Initial process authorization does not create commitments for descendant acts.

## Failure operators

The tranche separates:

```text
projection loss
prior contamination
recursive boundary expansion
defensive reflection without evidential transport
unsupported type promotion
behaviour-versus-consent collapse
```

The behaviour observer is explicitly non-injective: willing action and compliance under pressure can produce the same performed behaviour.

## Asymmetry

The assembled relational update kernel separates local operator equivariance from propagation equivariance.  Swapping participant identities may preserve the interaction rule while failing to preserve authority, dependency, capacity or later weave effects.

## Exact frontier

This tranche does not assert a psychological diagnosis, legal conclusion or universal empirical model.  It provides the typed distinctions and proof obligations needed to prevent lossy projections from being silently promoted into agreement, consent, obligation, completed repair or historical fact.
