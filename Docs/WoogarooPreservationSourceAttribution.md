# Woogaroo preservation source-attribution boundary

The preservation lane must preserve the repository provenance ladder:

```text
external source proposition
  != DASHI formal reconstruction
  != DASHI cross-source application
  != externally adjudicated finding
  != realised protective outcome
```

Examples:

- `Nature Conservation Act 1992 (Qld) s 13 defines critical habitat ...` is an external primary-legislation proposition.
- `Woogaroo satisfies s 13` is not licensed by the statutory text alone; it requires a same-land application receipt using ecological evidence.
- `s 49 provides a compulsory nature-refuge route` is a source-paid proposition about statutory power.
- `the Minister must use s 49 for Woogaroo` is a distinct proposition requiring a duty/constraint source and application receipt.
- `project delayed` is a procedural-state proposition.
- `project protected` is a distinct outcome proposition.

The cutset therefore treats every mechanism as:

```text
source authority
  + exact statutory/legal test
  + exact Woogaroo evidence
  + application receipt
  + decision / adjudication / outcome receipt
```

No earlier stage is silently promoted into a later one.
