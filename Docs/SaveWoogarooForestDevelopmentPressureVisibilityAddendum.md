# Save Woogaroo Forest — development-pressure / public-visibility addendum

This note is for Save Woogaroo Forest and assisting/pro-bono lawyers. It is not legal advice. It adds one fresh public-source lesson to the offset/development-pressure analysis: **public visibility and development pressure are not the same variable**.

## Fresh Ipswich witness: Swanbank data centre

Ipswich City Council Development.i currently records application **12285/2026/MCU** at Swanbank as:

- Material Change of Use — Warehouse (Data Centre);
- **Code** assessment;
- **Public Notification Required: No**;
- application still in progress;
- same historic property record also showing **13857/2025/OW — Earthworks and Associated with Vegetation Clearing** and **11711/2023/CA — Major Utility (Battery Energy Storage System)**.

Those are Council-source procedural/property-history facts.

Secondary reporting describes the proposed data centre as about 10 storeys / 72 m / 82,576 m2 and reports vegetation clearing and a State referral associated with mapped vegetation/core koala habitat. Those project-detail propositions should remain secondary until the underlying application documents are independently extracted.

## Why this matters to the Woogaroo offset counterfactual

The EPBC offset `risk of loss` question asks what is likely to happen to an offset site **without** the offset. A weak way to estimate that would be to look only for public controversy or publicly notified applications.

The Swanbank record demonstrates a live local counterexample:

```text
large development pressure
  +
code-assessable pathway
  ->
no statutory public notification
```

Therefore:

```text
no public notification
  !=
no development pressure
```

and:

```text
no obvious public campaign / submission history
  !=
low without-offset risk of loss
```

This does **not** set the risk of loss for Woogaroo or any proposed offset parcel. It changes the evidence demanded before assigning such a risk.

## Better parcel-level risk-of-loss audit

For every candidate offset parcel, counsel/ecologists should obtain:

1. exact lot/plan and polygon;
2. current zoning / planning designation;
3. any superseded planning scheme still capable of affecting an application;
4. code-assessable as well as impact-assessable development pathways;
5. existing material-change-of-use, operational-work or vegetation-clearing approvals;
6. subdivision, infrastructure, utility and access approvals;
7. existing development rights / preliminary approvals;
8. State referral triggers and exemptions;
9. conservation covenants / voluntary conservation agreements / Land for Wildlife / funded restoration obligations;
10. realistic physical development constraints.

Only after those are known should a numeric `without-offset risk of loss` be treated as defensible.

## Attribution firewall

```text
Ipswich Development.i record
  -> external source claim about Swanbank procedure/property history

news/campaign description of scale, koala mapping, water use etc
  -> secondary interpretation unless checked against application documents

Swanbank shows that public visibility can understate development pressure
  -> DASHI cross-source inference

therefore proposed Woogaroo offset parcel has high/low risk of loss
  -> NOT PROVED
```

Likewise:

```text
code assessment
  !=
improper assessment
```

and:

```text
Swanbank
  !=
White Rock
  !=
Springview / EPBC 2019/8575
```

The relevance is methodological and regional: it shows that lawful development pressure in Ipswich can exist without a public-notification signal.

## Counsel-facing question

> **For each proposed 2019/8575 offset parcel, what lawful development or clearing could occur without the offset, including code-assessable or pre-existing approval pathways that would not necessarily generate public notification?**

This is the right question for testing the proponent's risk-of-loss input. It is stronger than inferring risk from whether the parcel has appeared in recent public objections or media coverage.
