## B. Exact block quotient and sharp interface obstruction
Let block variables be x_i, with domain zero or one-hot. In its coordinate ring over any field, x_i^2=x_i, x_i x_j=0 for i!=j. For f=c+sum a_i x_i and g=d+sum b_i x_i, product constant is cd and linear coefficient i is c b_i+d a_i+a_i b_i. This follows by expansion, or independent evaluation at 0 and e_i. The last diagonal term is precisely absent from the formal disjoint-block recurrence. Tensor products of these rings across blocks give the quotient by the corresponding block ideals. The canonical representative is multilinear in blocks (at most one variable each); coefficients of the full-block component follow by inclusion-exclusion of zero-block evaluations. If f vanishes whenever any block is zero, full-block coefficients equal its all-one-hot evaluations. This is a scoped exact block projection; it discards multi-hot assignments and is not faithful on the full cube.
For evaluation matrices M,N across a fixed bipartition, rank(M Hadamard N)<=rank(M)rank(N): expand M=sum u_i v_i^T and N=sum a_j b_j^T; products are (u_i Hadamard a_j)(v_i Hadamard b_j)^T. This is sharp: for r shared equality coordinates, each equality matrix has rank 2; their Hadamard product is the identity on 2^r labels. Therefore counting overlap blocks or rank alone cannot pay an additive gate budget. A compressed linear interface for one specific flattening requires rank-many channels by elementary rank subadditivity; actual arbitrary computations need not use that interface.
Stronger full-cube control over GF2: f(x,y)=product_i (1+x_i+y_i) is exact equality on r-bit strings. Each factor uses disjoint variable pairs, hence w=b=t=0, 3r-1 arithmetic operations, but evaluation matrix across the fixed x|y cut is I_(2^r). At r=16 rank 65536 with 47 operations (32 inputs). No claim of a lower bound for arbitrary or varying balanced-cut decompositions; this is a refutation of any additive universal fixed-cut rank charge, even with zero overlap.
Graph block control: complete graph on k vertices, local label block size Q=2^(k-1), selecting incident edge-bit strings. Circuit = product of occupancy sums and all edge-bit equality checks. Over GF2 on zero/one-hot blocks, the coefficient tensor of the full-block projection is exactly the graph state-sum tensor (zero-block vanishing). Across any cut U|V, fixing internal labels zero gives identity minor indexed by the independent crossing bits: rank >=2^|delta(U)|; factorization by boundary labels also gives rank <= that. Proof is symbolic, not extrapolated from sampled ranks. For k=3,4,5,6,8, measured circuit gates 50,136,357,917,5726; max local block overlap t=2 always, b=w=k; balanced fixed-cut ranks 4,16,64,512,65536. With Q growing, tiny block overlap does not imply a small linear interface. Actual circuit size O(k^2 2^k); fixed balanced-cut rank 2^floor(k^2/4), superpolynomial in that size. Multiple-hot counterexample: choose labels 0,1 at one vertex, zero labels at others; graph polynomial has exactly one compatible monomial, but occupancy parity kills circuit. Thus this does not compute the state-sum polynomial on the full Boolean cube. It does not refute upstream formal E.4, nor an arbitrary sum over varying balanced partitions. The latter would require a separate partition-rank/spectral argument that handles nonlinear intermediate reuse.
