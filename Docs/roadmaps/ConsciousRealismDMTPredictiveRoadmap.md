## Decision criteria and attribution

- No accessible real dataset -> retain data-rights/reproducibility blocker; avoid synthetic-to-empirical claim promotion.
- Unconstrained model classes overlap -> no source-specific ontology discriminator; narrow models with independently grounded restrictions or explicitly report non-identification.
- No generalisable held-out improvement -> prefer simpler model; report failures.
- Null hidden-target trial -> only reject powered restricted channel claims, not all external-agent narratives.
- Above-chance hidden-target trial -> audit data security, ordinary channels, independent replication and alternative mechanisms *before* any ontological discussion.
- No credible validated ontology discriminator -> C4 remains open regardless of C1–C3.
- Original authors own published mathematical and empirical work; DASHI only owns stated formal reconstructions, deductions, audit scripts, and planned experiments. Do not count datasets reused in separate papers as independent replications.
