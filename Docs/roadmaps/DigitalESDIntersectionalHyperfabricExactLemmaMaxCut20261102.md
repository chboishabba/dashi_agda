## Main obligation

For each admitted and source-versioned study s, each original/decomposed/recomposed component p, and each declared research axis a from an extendible n-axis family, an accurate provenance-bound assessment must be available. An assessment may be directly reviewed, author-reported pending review, conditionally inferred, contested, *not yet assessed*, source-reviewed unmeasured, inaccessible or justified not applicable. These are not interchangeable. A question-dependent finite-arity hyperedge must include actual part/axis incidences, preserve the complete evidence-bearing stalk and source provenance, and either prove a compatible local section or retain an explicit obstruction. One source may point out a gap in another; it cannot fill absent participant observations by a common title, axis or mathematical theorem. Study selection, observer/author position, historical revisions and the research synthesis itself belong to the same hyperfabric.

No 3/9/27/369 visualization carrier, binary pair, seven principles, fixed ten score dimensions, nineteen PNF extraction coordinates or 55 source genealogy incidences determines the full world axis or interaction arity.

## Karp-style exact acceptance criteria (no shortcut)

1. **Search first and reuse original proof owners**. For each fresh claim, record owner path, source revision, original external authors, same-object identity, previous stronger donor and the exact lemma name.
2. **Separate carriers and costs**. An enumeration of research objects is a source-census statement, not a completeness proof. A global n-axis total function can be filled with `notYetAssessed`; it becomes a reviewed world only through actual source evidence. The computational cost of materialising a 43,996×n tensor is not justified, and a sparse higher-order world must retain coverage ledgers and missingness.
3. **Charge source membership explicitly**. For each reviewed assertion, exhibit *actual* same-source full-text hash/revision, original source passage, SLR observation and review receipt, source audit membership, question-specific claim ceiling, authority and context transfer.
4. **Prove the source/consumer theorem**. Complete lossless roundtrips or explicit nonfactorability witnesses on the relevant study objects. Generic synthetic Crenshaw/parity fixtures cannot become measured interaction claims.
5. **Require higher-order semantics**. A relation has ≥1 named participant and ≥1 named axis, all participants are incident to the same actual edge, local restrictions agree only when witnessed, conflict can remain and review is a separate proof.
6. **Maintain epistemic and historical revisions**. Each changed source observation and reviewed interpretation must make a dependency-scoped reopening/retention receipt; the researcher and synthesis themselves are not exempt from accountability.
7. **Execute independent checks on exact head**. The Dashi pinned Agda toolchain, focused imports, Python tests, live current SLR/Postgres retained-data run, reviewer/source version and coauthor adjudication must each have separately recoverable receipts before final promotion.
8. **Report the actual status**. A file written to GitHub != typechecked Agda != tested Python != validated source span != human-approved paper Result. Keep all blocker statuses source-written/open until paid.
