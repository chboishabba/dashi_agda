## B-M7c — exact two-lobe barycentre residual and BIDI transport
Push forward the actual signed measure F(t)dt on t in [1,infty) by x=(log t)^2. Let mu be the result and M_j=int x^j dmu, so Lambda^(2j)(1)=2 M_j. The two actual roots give ordered finite x1<x2. Write mu=mu_L+mu_R−nu, with nonnegative measures supported in x<x1, x>x2, x1<x<x2 respectively, ignoring zero-density endpoints. Each has positive mass. Already-proved M0=0 gives m=nu(R)=mu_L(R)+mu_R(R)>0. Set rho_L=mu_L/m_L, rho_R=mu_R/m_R, eta=nu/m, p=m_R/m, and means b_L<b_N<b_R (b_N=int x d eta), since the supports are strictly separated. Then
M1/m = (1−p)b_L+p b_R−b_N = (p−p*) (b_R−b_L),
p*=(b_N−b_L)/(b_R−b_L).
Actual p,p* in (0,1). Define K(x,dy)=[(b_R−x)/(b_R−b_L)]rho_L(dy)+[(x−b_L)/(b_R−b_L)]rho_R(dy) for x in middle support. Its coefficients are probabilities, conditional mean int y K=x, and eta K=(1−p*)rho_L+p*rho_R. This gives an explicit mean-preserving transport, not an existence assumption. It equals the ACTUAL normalized outer positive measure iff p=p*, iff M1=0, iff the missing Lambda''(1)=0. Conversely any mean-preserving transport between the actual measures forces equal means by integration; no extra hypothesis. Exact decomposition
mu/m=(eta K−eta)+(p−p*)(rho_R−rho_L).
The first term is an explicit mean-preserving spread with zero zeroth/first moments; the second is the remaining signed barycentre mismatch. For strictly convex x² the first term has strictly positive second moment by conditional variance; the actual spread has that property if the mismatch vanishes. Equivalently int (x−x1)(x−x2)dmu = M2−(x1+x2)M1>0, independently of mismatch. Therefore M1=0 implies M2>0, and gives a=4. If M1!=0 then a=2.
