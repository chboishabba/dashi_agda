## 17 Nov further continuation — B3 correctness audit against original CDO conventions

**Two material comparator bugs found and fixed (source-written in #1525, 14/14 local tests):**

1. **Multi-variable station undercount.** The prior pre-2000 loss grouping iterated station/product keys and assigned a station-only dictionary key, silently overwriting `tmax` with `tmin` (or vice versa) when both products lost readings. New implementation aggregates **per loss event**, retaining both whole-station and station:variable loss counts. A two-product same-station adversarial fixture reproduces the original failure shape and now passes.
2. **Blank accumulation is not a missing measurement.** Native BOM daily CDO rows sometimes have a present reading and blank accumulation-days; this denotes a normal one-day observation. A blank field versus explicit `1` must not register `accumulation_changed`. Preserve genuinely empty observation values as missing. Added two regression cases.
