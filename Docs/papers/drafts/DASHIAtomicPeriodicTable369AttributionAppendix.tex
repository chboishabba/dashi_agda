\section{Identifier-rich provenance register}

Dewey supplies a catalogue coordinate; an OEIS identifier supplies an integer-
sequence coordinate; and a repository commit supplies an implementation receipt.
None of these fields, by itself, proves the physical claim represented by the source.

\paragraph{Priority versus publication.}
The 3 January 2026 \texttt{dashiQ} commit is the earliest located public/repository
source in this audit that explicitly states the periodic-table/kernel-filling
programme.  The immediately preceding inspected README state is only the two-line
repository title, so the addition boundary is exact at repository level.  This
pays public-source priority/provenance; it is not called peer-reviewed publication
and does not convert the historical phrase ``we did'' into a kernel-checked theorem.

\paragraph{Ibrahim/Dewey traversal.}
The repo-native traversal policy follows the Ibrahim first-link discipline while
preferring typed DASHI formulation/dependency edges over lexical adjacency.  The
most useful external catalogue walk located in this tranche is
\[
\text{periodic table }(Q10693,546.8)
\to \text{chemical element }(Q11344,546)
\to \text{atom }(Q9121,539.7)
\to \text{atomic orbital }(Q53860,541.28)

Carbon $(Q623,547)$ is retained as a downstream chemistry branch. Ionization

next scale/method coordinates, but their Dewey fields remain unresolved in the
inspected semantic items. This walk is a search funnel, not a theorem implication:
Dewey adjacency, QID identity and first-link centrality carry no proof authority.

\paragraph{OEIS sequence weld.}
Following the repository's earlier OEIS practice, sequence identifiers are now
attached as non-promoting mathematical coordinates.  The strongest exact matches
are
\[
\begin{aligned}
\text{A016825}:&\quad 2,6,10,14,\ldots = 4\ell+2
               = 2(2\ell+1),\\
\text{A001105}:&\quad 0,2,8,18,32,\ldots = 2n^2,\\
\text{A006331}:&\quad 0,2,10,28,60,\ldots
               = \sum_{k=1}^{n}2k^2,\\
\text{A093907}:&\quad 2,8,8,18,18,32,32,\ldots
               \quad\text{(Aufbau-predicted period lengths)},\\
\text{A018227}:&\quad 2,10,18,36,54,86,118,\ldots
               \quad\text{(full-shell/noble closure coordinate)}.
\end{aligned}
\]
Thus DASHI's exact subshell-capacity function coincides with A016825 and its
principal-shell capacity coincides with A001105.  The historical $2,10,18$
closure regression is a three-term prefix of A018227.  Crucially, A093907 is
\emph{not} globally identical to $2n^2$: period length and principal-shell
capacity are different sequence objects once the filling order is considered.
OEIS A018227 records itself as the partial sums of A093907, which makes the
closure/period relation a useful source coordinate without proving the DASHI MDL
selector.  A sequence match does not establish mechanism identity, physical
Hamiltonian authority, nuclear stability, or empirical recovery.

OEIS A093907 also provides the useful literature snowball to Restrepo and
Pach\'on, \emph{Mathematical Aspects of the Periodic Law}, DOI
\texttt{10.1007/s10698-006-9026-6}, arXiv:math/0611410.  This pays a primary
mathematical-chemistry literature coordinate for period-length mathematics; it
still does not identify that paper's mechanism with DASHI's 369/kernel/MDL route.
