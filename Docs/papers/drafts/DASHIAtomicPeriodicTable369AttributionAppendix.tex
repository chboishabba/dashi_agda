\section{Identifier-rich provenance register}

This appendix keeps discovery identifiers separate from scientific authority.
A DOI identifies a publication object; a QID supplies a semantic coordinate;
Dewey supplies a catalogue coordinate; an IUPAC Gold Book identifier supplies a
terminology coordinate; an OEIS number supplies an integer-sequence coordinate;
and a repository commit supplies an implementation receipt. None of these fields,
by itself, proves the physical claim represented by the source.

\paragraph{Exact selector repair and fixed-$\alpha$ boundary.}
The historical archive uses
\[

\]
and records early closures $2,10,18$. The current typed repair generates orbitals
directly in lexicographic $(n+\ell,n)$ order. For $\alpha=3/5$, the historical
proxy gets $4s<3d$ but incorrectly puts $4f<6s$ relative to Madelung, so it is
retained as finite historical evidence rather than silently renamed as the global
selector.
