Dewey supplies a catalogue coordinate; an IUPAC Gold Book identifier supplies a
terminology coordinate; an OEIS number supplies an integer-sequence coordinate;
and a repository commit supplies an implementation receipt. None of these fields,
by itself, proves the physical claim represented by the source.

\paragraph{Exact selector repair and historical fixed-$\alpha$ boundary.}
The attached historical archive uses the toy score
\[
C_\alpha(n,\ell)=n+\alpha\ell
\]
and records early closures $2,10,18$. The archive also reports that $\alpha$
changes the $4s/3d$ competition. The current formal archaeology preserves those
runs, but no longer identifies a fixed $\alpha$ with the global Madelung rule.
For the representative $\alpha=3/5$, multiply by five:
\[
\widehat C(n,\ell)=5n+3\ell.
\]
Then
\[
\widehat C(4s)=20<21=\widehat C(3d),
\]
which gives the desired early ordering, but
\[
\widehat C(4f)=29<30=\widehat C(6s),
\]
whereas Madelung diagonals give
\[
(n+\ell)(6s)=6<7=(n+\ell)(4f).
\]
Thus the fixed-$\alpha$ proxy is a retained finite historical producer, not the
full Aufbau selector.

A later typed repair now generates orbitals directly in lexicographic
$(n+\ell,n)$ order. Its capacity image definitionally produces finite prefixes of
A167268 without any fixed $\alpha$. This is structural selector mathematics,
not a claim that empirical interacting-atom ground states have no exceptions.

\paragraph{Same-object period/closure weld.}
The exact selected subshell stream through $7p$, followed by the next $8s$
boundary marker, is now partitioned into the first seven periods:
\[
\begin{array}{ll}
1:&1s,\\
2:&2s,2p,\\
3:&3s,3p,\\
4:&4s,3d,4p,\\
5:&5s,4d,5p,\\
6:&6s,4f,5d,6p,\\
7:&7s,5f,6d,7p.
\end{array}
\]
Applying $2(2\ell+1)$ to these same selected blocks gives exactly
\[
2,8,8,18,18,32,32,
\]
the first seven values of A093907. Their cumulative sums are
\[
2,10,18,36,54,86,118,
\]
the corresponding A018227 closure values. This is stronger than the earlier
three-term $2,10,18$ adjacency: the bounded first-seven period/closure weld now
uses the same selected subshell objects. It is still not an empirical theorem of
nuclear stability, measured spectra, or ionization energies.
