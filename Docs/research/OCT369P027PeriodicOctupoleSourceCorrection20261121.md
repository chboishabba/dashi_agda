# OCT369 P0.27 physical Pt inversion and periodic magnetic octupole source correction

## Exact conclusion and why previous P0.26 is limited
The original L12 cubic cell has Pt at 1a=(0,0,0) and Mn at 3c=(0,1/2,1/2), (1/2,0,1/2), (1/2,1/2,0). The Pt site is a crystal inversion centre modulo integer lattice translations: -p_i=p_i+T_i, with T_i integral. The centroid of the 3c Mn triangle is (1/3,1/3,1/3), but 2*centroid-p_i is not a crystal Mn site modulo the simple cubic lattice. Hence P0.26 inversion-completes a *toy* 3-Mn triangle around a non-crystal inversion centre, not an experimentally verified bulk PtMn3 motif. P0.27 uses actual Pt-centred inversion-related lattice images and retains all six physical sites.

For selected trial 120 degree axial spins, the Pt-centred six-site STF Cartesian Mxyz = -sqrt6 a² mu/6, three times P0.26's artificial Mxyz. At the same chosen harmonic scalar-potential gradient, the [111] static magnetic force remains -3 a² mu k4, an equality specific to that source and finite grouping. No general identification of magnetic T1g cluster order, Cartesian point-dipole octupole, and the gauge-invariant band/thermodynamic magnetic octupole follows.

## Source-isolation and image-change counterexample
A lattice basis representative can be relabelled p_i -> p_i+T_i if the unit-cell index is simultaneously shifted by -T_i. The actual atom position stays fixed; so does its physical magnetic force. Failing to shift the cell index *changes the selected physical finite atoms*. The example p_0 -> p_0+(1,1,0) changes finite-sample force from -3 a² mu k4 to +a² mu k4. This is not a physical gauge anomaly: it is a mismatch between representative relabel and finite sample geometry. Bulk quantities require a fixed bounded sample or the rigorous periodic electronic/thermodynamic formulation.

## End-to-start physical scale test
The prior numerical model assumed 10^24 six-Mn inversion motifs all inside a gradient varying on 1mm. That violates its own lattice packing: using a=0.4nm and 6 atoms per 2 conventional L12 formula cells, V=2N a³=1.28e-4m³, an ~5.04cm cube. If a 1mm cubical active region is instead assumed, ideal non-overlapping pair count is N=1mm³/(2a³)=7.8125e18. Set reference source field B_ref=10T at a point 1mm from the expansion origin (NOT a global maximum), so quartic harmonic k4=B_ref/L³. The selected P0.26 force becomes 3 mu B_ref/(2a) ~1.0433e-12 N with illustrative mu=3mu_B. Not a universal levitation limit, no actual material or control field fitted. The essential next work is an actual Maxwell source in the same bounded region with calibrated field profile, boundaries, motor reaction, current/heat and material domains.
