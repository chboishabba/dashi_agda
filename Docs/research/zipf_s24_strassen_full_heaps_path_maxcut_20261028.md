## Exact typed mathematical assertion and meaning of the receipt

For a positive integer histogram f of K labeled types with total N, define `μ_f^{sampler,t}` as the exact probability distribution of the **whole** discovery curve `(V_0,...,V_t)` generated by the already-owned finite sampler. The two samplers are:
1. IID replacement, probabilities `f_i/N` independently on every draw.
2. Uniform permutation of N individually distinguishable tokens, type i repeated f_i times, without replacement, t≤N.

For positive histograms `f ≽ g` with identical K and N, the finite stochastic path order we seek is equivalent to the existence of nonnegative rational weights `γ(x,y)` satisfying

```
Σ_y γ(x,y) = μ_f(x)          for each left path x
Σ_x γ(x,y) = μ_g(y)          for each right path y
Σ_{x,y} γ(x,y) = 1
γ(x,y) > 0 ⇒ x_s ≤ y_s      for every s=0,...,t
```

The new code builds these weights via exact rational Edmonds–Karp max-flow on the bipartite support graph. It rejects invalid majorization, invalid counts/sampler/time, excessive state budgets and nonexact probability masses. The returned `PathTransportCertificate.validate()` rechecks every row, column, positive entry, total and **all-prefix** coordinate-order constraint.

**Precise scope:** A returned certificate is an actual exact proof witness for the **specific finite input distributions**, assuming the independently checked full-path PMFs are correct. It is stronger than a separate one-time stochastic dominance test for each t, because it carries one coupling across ALL prefixes up to the selected t. It is not automatically one consistent coupling for every possible infinite horizon, and is not a general Agda theorem for all histograms. Python `assert` checks are executable evidence, not kernel proof objects.

## Dual MAX-CUT obstruction: equal single-time marginals do not suffice

The new solver also has `finite_hall_cut_obstruction(left_law,right_law)`. For a subset A of left curves, let `up(A)` be the set of right curves y that dominate at least one x in A at **every prefix**. A positive exact deficit

```
deficit(A) = P_left(A) - P_right(up(A)) > 0
```

is a directly verifiable dual cut proving that **no** monotone path coupling can exist for the two given full-path laws. This is classical finite Hall/Strassen max-flow/min-cut duality, not a new discovery.

**Adversarial example using only valid finite Heaps curves:**

```
μ_X = 1/2 δ_(0,1,1,2,2) + 1/2 δ_(0,1,2,2,3)
μ_Y = 1/2 δ_(0,1,1,2,3) + 1/2 δ_(0,1,2,2,2).
```

At **every individual prefix t**, `V_t` has the same distribution under X and Y; in particular, all single-time first-order stochastic dominance inequalities hold as equalities. Yet the full path measures differ. The upper path `(0,1,2,2,3)` in X has no dominating right path in Y; taking A to be that singleton gives **exact deficit 1/2**. The maximum feasible monotone transport mass is therefore **1/2**, not 1. This is a counterexample to promoting **one-time stochastic dominance** into **joint-history stochastic dominance**, not a counterexample to the majorization-specific S24 conjecture. The two mixtures are constructed path measures, not asserted to be generated by any particular Zipf count vectors.

The committed regression includes both a positive exact transport case and this adversarial dual obstruction. A separate independent local Fraction calculation confirmed deficit 1/2 and that all one-time marginals coincide.

## Universal proof route (mathematical outline; Agda obligations still unpaid)

A plausible complete proof follows the *actual two-sampler finite model*, not synthetic receipts:

**S24.1** Robin Hood transfer chain: every integer majorization relation with identical K,N reduces to a finite sequence of pair transfers and relabelings. Preserve strict positivity of counts during each step.

**S24.2** Common pair-versus-other schedule: for one transfer altering only a pair of counts a,b while preserving a+b, couple the indicator schedule for draws from the pair identically in both models. For IID the pair-selection probability is `(a+b)/N`; for the permutation sampler exactly a+b of the N positions belong to the pair. Couple all *other* type labels identically.

**S24.3** Conditional first switch: after m≥1 draws from the pair, the pair contributes two discovered types unless both labels were identical. Under IID with conditional type probability `q=a/(a+b)`, the single-type-survival probability is `q^m+(1-q)^m`. Under fixed-multiset permutation, it is `[C(a,m)+C(b,m)]/C(a+b,m)`, with `C(n,m)=0` for m>n. For **m=0**, no pair type has appeared and its discovery count is 0; do not insert m=0 into the m≥1 formulas (which would incorrectly give 2).

**S24.4** Monotone pair switch-time law: when a≥b and one token is moved from the smaller to the larger positive type, the probabilities of *still having only one observed pair type* cannot decrease at any m. For IID this is convexity of `q^m+(1-q)^m` as the pair becomes more imbalanced; for permutation it is discrete convexity of `C(a,m)+C(b,m)` for fixed a+b. m=1 has equality and m=0 is treated separately.

**S24.5** Conditional *entire-path* coupling: construct the pair switch-time variables by inverse-CDF common uniform coupling, so the concentrated system's second pair type is discovered no earlier. Condition each pair's actual label sequence on its switch time to restore the correct marginal process. Combine with the shared outer schedule and unchanged-type stream to obtain one coordinatewise dominated **full Heaps path** coupling for each finite horizon.

**S24.7** Transport/duality: prove exact finite rational max-flow certificate soundness and the Hall upper-set obstruction, reusing existing finite distributions.
