## Reproducible runtime contract

`scripts/ibrahim_fln_reference_analysis.py` ingests an explicit mapping `{"article": "destination" | null}`, checks SHA-256 against an independently supplied manifest, computes terminal cycles/dead ends/unresolved targets, exact fraction basin shares, inclusive distinct-start counts, separately attributed traversal-visit counts, published-figure traversal-funnel counts, and the unamended-pseudocode alternative; then optionally compares two versions with identical node carriers. It rejects source-node-set changes rather than silently equating page identities.

Example:

```sh
python3 -m unittest tests/test_ibrahim_fln_reference_analysis.py
python3 scripts/ibrahim_fln_reference_analysis.py \
  --input /path/to/released-or-current-fln.json \
  --manifest /path/to/exact-attributed-input-manifest.json \
  --output /path/to/nonpromoting-census.json
```

Required manifest keys: `source_author`, `source_title`, `canonical_url`, `source_role`, `version_or_revision`, `parser_policy`, `link_selection_policy`, `expected_sha256`, `claim_scope`, `qid_status`, `dewey_status`. An absent DOI must be explicitly represented in wider source attribution; the script never mints one. Large JSON inputs are currently decoded in memory, so full-scale 505 MB use has not been memory-qualified.

### Historical algorithm discriminator added 2026-11-14

The 2016 author-hosted manuscript [Figures 2–4](https://compstorylab.org/share/papers/ibrahim2016a/paper/2015-11-wikipedia-network.pdf) defines a seven-node graph `A→B→C→A; D→C; E→C; F→E; G→E`. Its Fig. 2 traversal-visit row counts are `A=B=C=7; E=2; D=F=G=0`. Its Fig. 3–4 traversal funnels are `C=4, E=2`, all other nodes zero. To reproduce those figures, count arrival visits after the starting vertex for noncycle nodes, count all basin starts on cycle vertices for visits, and count *first cycle entry only* for funnels. The printed early pseudocode does not increment the cycle entry, whereas the author source chronology records a 2019 correction. The implementation retains both semantics separately. A passing synthetic figure test would pay only **source-figure algorithm agreement**, not full historical production equivalence. The figure and pseudocode conflict must stay in the attribution ledger rather than one retroactively rewriting the other.
