## Reproducible runtime contract

\`scripts/ibrahim_fln_reference_analysis.py\` ingests an explicit mapping \`{"article": "destination" | null}\`, checks SHA-256 against an independently supplied manifest, computes terminal cycles/dead ends/unresolved targets, exact fraction basin shares and single-visit counts, then optionally compares two versions with identical node carriers. It rejects source-node-set changes rather than silently equating page identities.

Example:

\`\`\`sh
python3 -m unittest tests/test_ibrahim_fln_reference_analysis.py
python3 scripts/ibrahim_fln_reference_analysis.py \
  --input /path/to/released-or-current-fln.json \
  --manifest /path/to/exact-attributed-input-manifest.json \
  --output /path/to/nonpromoting-census.json
\`\`\`

Required manifest keys: \`source_author\`, \`source_title\`, \`canonical_url\`, \`source_role\`, \`version_or_revision\`, \`parser_policy\`, \`link_selection_policy\`, \`expected_sha256\`, \`claim_scope\`, \`qid_status\`, \`dewey_status\`. An absent DOI must be explicitly represented in wider source attribution; the script never mints one. Large JSON inputs are currently decoded in memory, so full-scale 505 MB use has not been memory-qualified.

### Explicit negatives

- **No claim of exact source replay:** a non-promoting census, a source report, a regression test and a seven-node Agda fixture cannot certify the original complete data or parser.
- **No claim of Agda kernel acceptance yet:** no local Agda toolchain was available in the tool environment when the branch was authored. Any CI/validation later must be recorded separately.
- **No QID-based semantic parity:** multi-edition sitelink identity is not a translation or claim-equivalence proof.
- **No ternary zero as generic unknown:** missing alignment, both-sides evidence, epistemic neutral and conflicting support must retain original typed residuals until warranted.
- **No universal cultural/causal inference:** wiki link order may vary by writing systems, editorial communities, revisions, extraction, article coverage and other confounders.
