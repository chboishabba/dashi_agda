# Missing/deceased scientist investigation — open-science / knowledge-release matrix

## Working hypothesis

The parent hypothesis is now:

> **H_O — some roster members may be unusually concentrated at the boundary where technically important knowledge is moved into wider public circulation.**

This is intentionally broader than UAP disclosure and narrower than "they were scientists who published papers."

## Fixed coordinates

- **O1 — public technical publication:** papers, patents, technical reports or other substantive technical artefacts released publicly.
- **O2 — open code/data/methods:** public source repositories, reusable data, reproducible methods or equivalent open technical artefacts.
- **O3 — public technical education:** talks, interviews, public technical explanations or educational outreach attributable to the person.
- **O4 — disclosure/transparency advocacy:** an explicit position favouring wider disclosure/transparency.
- **O5 — suppression/secrecy critique:** an explicit criticism of suppression, classification or private containment of technical knowledge.
- **O6 — restricted/private -> public same-object transfer:** the strongest coordinate. Requires evidence that one exact knowledge object was previously restricted/private, was later released publicly, and is the same object across both states.

Behaviour and belief are separate. Institutional publication can establish behaviour without proving personal ideology.

## Viewpoint x-pollination

The old V1-V6 viewpoint lane is now subordinate where semantics actually overlap.

Direct bridges currently permitted:

- **V1 UAP disclosure support -> O4 disclosure/transparency advocacy**
- **V4 secrecy/classification critique -> O5 suppression/secrecy critique**
- **V5 willingness to disclose sensitive technical material -> O4 disclosure/transparency advocacy**

The following do **not** automatically imply open science:

- V2 belief in suppressed/exotic propulsion;
- V3 transformative fusion-energy expectation;
- V6 belief in hidden major capability.

Those require an independent openness/release receipt.

## Why O6 matters most

O1 is likely common among matched scientists. O3 may also be common among senior public-facing researchers. O4 and O5 are rarer, but they are still beliefs/positions.

O6 is potentially much more discriminating:

```
prior restricted/private state
        +
public release state
        +
same-object provenance
        =
actual knowledge-release boundary crossing
```

Without all three components, O6 remains unknown.

## Matched-control test

The feature rubric is fixed before controls are scored. Controls should be matched within institution/field/seniority/time and also on **publication opportunity**, otherwise the trivial fact that senior scientists publish will manufacture an apparent signal.

The key comparisons are therefore not simply:

- roster publishes vs controls publish;

but:

- O2 open artefacts beyond ordinary publication expectations;
- O4 explicit transparency/disclosure advocacy;
- O5 explicit anti-suppression/secrecy position;
- O6 genuine restricted-to-public boundary crossing.

## Selector test

Even enrichment is not yet a selection explanation. A further receipt must identify a real observer/system capable of seeing the openness feature itself.

Candidate observer surfaces to test:

- publication/repository and conference networks;
- programme review and public-release approval processes;
- technology-transfer and patent systems;
- public-affairs/disclosure review systems;
- contractor/funder review surfaces;
- security/classification or declassification review surfaces, where public provenance exists.

A public internet observer has coverage but is probably too coarse. The useful observer would have to distinguish **who is unusually pushing important knowledge outward** from ordinary public scientific activity.
