# Missing/deceased scientist investigation — open-science acquisition pass (2026-09-05)

## Purpose

Test the highest-value open-science coordinates directly, especially whether any named person demonstrably moved a same technical object from a restricted/private state into public circulation.

## Main result

The pass strengthens **public dissemination** evidence but does **not** yet establish a clean O6 restricted/private -> public same-object transfer for any of the priority technical cases.

That is an important negative result. It prevents ordinary papers, patents, webinars, public talks, or disclosure advocacy from being inflated into declassification/restricted-release claims.

The 2016 Viriato paper and public APS abstract expose numerical architecture, algorithms, representations and benchmark behaviour.

Sources:
- MIT PSFC profile: https://www-new.psfc.mit.edu/people/faculty/nuno-loureiro

### Correction

Public documentation of a computational code is not the same as public release of its source tree.

Current state:

- public benchmark disclosure: **SUPPORTED**;
- public source-code release under an identifiable licence/versioned repository: **UNRESOLVED**;
- O6 restricted->public transfer: **UNRESOLVED**.

A 2023 MIT student project (`JULIATO`) has an open-source GitHub repository and acknowledges Loureiro for discussions/support, but it is a distinct project and must not be same-object welded to Viriato.

## Cross-case conclusion

The strongest currently shared feature is therefore **public technical externalisation**, not proven declassification or anti-secrecy ideology.

For several people, outsiders can inspect substantial parts of the chain:

`problem -> model/design -> method -> benchmark/test -> public technical explanation`.

That is potentially more discriminating than publication count alone, but it still requires matched controls.

The highest-value remaining open-science tests are now:

1. locate genuine open-source/data artefacts attributable to the named person, with version/licence provenance;
2. locate direct first-person transparency or anti-secrecy statements for McCasland, Reza, LeBlanc, Maiwald and Chavez;
3. search declassification/public-release review records for exact same-object O6 cases;
4. compare the roster against matched peers on **technical externalisation depth**, not simply whether they published;
5. identify real observers who could distinguish unusually strong externalisation/disclosure behaviour from routine scientific publication.

## Stop condition

Do not promote O6 unless all three are present:

- prior restricted/private state;
- later public release;
- same-object provenance.

Do not treat a public paper, patent, webinar, or source-described code as proof of open-source release, declassification, or personal anti-secrecy ideology.
