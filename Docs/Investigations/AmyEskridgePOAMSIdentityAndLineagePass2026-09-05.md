## Object-lineage correction

The evidence should not be treated as one object. At minimum the current record distinguishes:

1. **2015-2016 NASA MSFC / Quantum Machines experimental study**;
2. **2021 NASA Technical Memorandum reporting that programme**;
3. **Institute for Exotic Science derived/matured work described by Amy**;
4. **Amy's September-2020 unnamed NASA-review / IP object**.

The 2021 TM is a later report about the experimental programme. Derived Institute work is also not definitionally the same object as the NASA study.

Thus:

`laterReportAbout(study) != sameObject(study, report)`

and:

`derivedFrom(study) != sameObject(study, derivative)`.

## Primary proprietary-boundary evidence

The POAMS report itself describes the V5 programme as follows in substance:

- NASA MSFC helped Quantum Machines build the V5 rotor;
- successful V5 tests produced data;
- the V5 and V5 data remained in Quantum Machines' possession;
- no further NASA MSFC work continued during limitations imposed by the Space Act proprietary period;
- by the time of writing, that proprietary period had ended and NASA could continue the research without that limitation if desired.

This is a genuine primary-source proprietary-boundary receipt.

But it supports only:

`proprietaryPeriod existed -> proprietaryPeriod later ended`.

It does **not** prove:

- all V5 data became public;
- the V5 hardware became publicly accessible;
- all underlying knowledge crossed into the public domain;
- Amy's 2020 review object was the same object as the final TM.
