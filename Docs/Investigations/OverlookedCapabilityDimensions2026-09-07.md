This pass broadens the missing/deceased-scientist investigation beyond scientific secrecy and technical sophistication.

## Core correction

A historical technical role is not the same proposition as event-time possession of a capability-bearing application transformation.

The investigation must now distinguish:

- governing/public science;
- application configuration/calibration/closure/operating window;
- event-time possession/access;
- physical hardware and data custody;
- codification quality (SOPs, notebooks, source repositories, configuration management);
- organisational resilience and named succession;
- mergers/acquisitions/reorganisations and resulting access/role changes;
- project/funding/procurement transitions;
- event-specific alternative evidence.

## Resilience coordinates

The new resilience calculus tests:

- named successor;
- overlapping team;
- SOPs;
- notebooks/repos;
- configuration management;
- calibration archive;
- qualification archive;
- failure-history archive;
- hardware custody continuity;
- access transfer;
- cross-training;
- external replication.

A programme that continues after a departure can still have a lost tacit carrier. Conversely, a dramatic personnel loss can be technically low-impact if the transformation is well codified and redundantly held.
