# Missing/deceased scientist investigation — empirical evidence matrix

## Purpose

This file is the working investigation ledger. It is deliberately not another ontology. Its job is to answer four empirical questions:

1. Is the roster actually unusual relative to matched peers?
2. Did loss of a named person produce unusual technical or programme disruption?
3. Which real observer surfaces could recognise that person's capability value?
4. Is there any case-specific evidence connecting an actor to an event?

`unknown` means evidence has not yet been located or evaluated. It does not mean false.

## Status vocabulary

- **SOURCEBACKED** — primary publication, patent, institutional, programme or official-role receipt exists.
- **PARTIAL** — some source-backed coordinates exist but the requested inference is not closed.
- **LIVE** — concrete acquisition target; evidence not yet located.
- **WEAK/NEGATIVE CONTROL** — current evidence fits the proposed feature weakly and should count against an over-broad hypothesis.
- **UNASSESSED** — not yet researched at the required level.

## BIDI “knew too much” test

The phrase is operationalised as **critical nonpublic/tacit knowledge concentration**, not as a conclusion that anyone possessed secrets.

A strong claim now requires independent evidence on all five criticality coordinates:

1. **uniqueness** — was the knowledge or role genuinely rare or single-point?
2. **nonpublicness** — was material knowledge unavailable from ordinary public sources?
3. **integration breadth** — did the person span multiple systems/programmes/interfaces?
4. **replacement difficulty** — did substitution or responsibility transfer prove unusually hard?
5. **strategic relevance** — did the knowledge materially bear on an important capability?

### Reverse acquisition frontier

A “knew too much” claim must now compile backward into exact evidence targets rather than into more narrative:

- **Loureiro:** authenticated nonpublic/advisory/programme role plus student/research-direction transfer.
- **Chavez:** subsystem ownership, design-authority matrix, successor, rare qualification/failure-mode responsibility.
- **McCasland:** ATA/BlueHalo IRAD and technology-strategy succession; event-time portfolio; any role-specific restricted-access receipt.
- **LeBlanc:** post-July-2025 SNP I&C TechMat successor; configuration/responsibility-transfer evidence.
- **Reza:** primary JPL Materials Processing role, manufacturing/scale-up ownership, successor, primary AFRL contract lineage.
- **Maiwald:** SBG-VSWIR management successor, process qualification handover, schedule/budget effects.

The absence of one of these receipts does not prove the corresponding coordinate false; it leaves that coordinate unresolved. Conversely, seniority, long tenure, a sensitive field, or an impressive publication record cannot substitute for the missing receipt.

## Stop rule

Do not add a new explanatory layer merely because an existing hypothesis has an empty cell. Prefer acquiring the missing receipt. New formal machinery is justified only if the existing ledger cannot represent a genuinely different evidence type or test.
