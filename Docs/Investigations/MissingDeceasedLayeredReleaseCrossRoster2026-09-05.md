# Missing/deceased scientist layered-release cross-roster pass — 2026-09-05

## Question

Does the open-science / boundary hypothesis become more discriminating when the knowledge object is split into layers rather than treated as one public/private Boolean?

Fixed layers:

- governance restriction;
- public technical report;
- underlying data;
- physical hardware;
- implementation know-how;
- derived/private results.

A **documented partial release** requires:

1. a public technical report; and
2. at least one underlying layer independently documented as bounded or in private custody.

`unknown` does not count as private.

## Missingness-controlled denominator requirement

A valid comparison population for the stronger layered boundary hypothesis must include only programmes for which underlayer status has actually been inspected with comparable source effort.

Do not calculate:

`P(documented partial release | roster)`

against controls whose data/hardware/know-how status is merely unsearched or unknown.

The next acquisition target is therefore programme-specific evidence for controls and roster peers that explicitly states whether underlying data, hardware or implementation material remained proprietary/restricted/private or was publicly released.

High-value control classes:

## Firewalls

- public report != public underlying data;
- public report != public hardware access;
- public report != public implementation know-how;
- unknown != private;
- documented partial release != restricted-to-public transfer of every layer;
- POAMS documented layer contrast != Amy-specific completed boundary transition;
- apparent uniqueness under asymmetric documentation != roster enrichment;
- enrichment != targeting, actor identity, motive or harm.
