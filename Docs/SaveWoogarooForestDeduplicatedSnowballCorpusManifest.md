## Visual-review rule

Every PDF is reviewed in two distinct channels where applicable:

1. parsed text / searchable carrier; and
2. rendered page image / figure / map / table / scan.

The visual channel can create a Snowball atom only when the page itself supports that observation. It does not inherit legal status from nearby prose.

Required visual-review states:

- `textReviewed`
- `pageImagesReviewed`
- `spatialFigureReviewed`
- `duplicateCarrier`
- `sourceOfSourceEdgeRecorded`
- `outstandingAcquisition`

Firewalls:

- `image observation != parsed-text claim`;
- `map alignment != exact GIS intersection`;
- `visual similarity != same parcel`;
- `campaign annotation != official geometry`;
- `developer figure != agency finding`;
- `historical aerial persistence != ecological condition theorem`.

## Attribution discipline

For every Snowball atom retain:

`(carrier, page/figure, author-or-issuer, project/referral, source-role, proposition, provenance-stage, legal-consumer, residual)`.

Canonical provenance stages remain:

- external source claim;
- secondary source interpretation;
- repository reconstruction;
- cross-source inference;
- repository theorem extension;
- promotion/external adjudication.

No visual or textual observation is promoted across those stages without a receipt.
