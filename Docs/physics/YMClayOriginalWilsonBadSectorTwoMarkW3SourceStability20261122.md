- 0 <= p_st <= min(1, exp(2rho)*p_00)
- |partial_s p_st| <= 2 p_st
- |partial_s partial_t p_st| <= 5 p_st

    partial_s p = E[1_B (F-E[F])]
    partial_s partial_t p =
      E[1_B (F-E[F])(G-E[G])] - p Cov(F,G).

These statements require no independent Wilson plaquettes, no selected cluster gas and no high-temperature expansion. They are valid for any finite original Wilson Gibbs measure and real marked sources.
