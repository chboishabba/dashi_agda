## 4. Crucial no-promotion: state change ≠ gauge-background change

**When `g,A` are the SAME:** `Λ₁−Λ₀` is smooth for Hadamard states, and the local reference singularity/finite counterterm cancels. Any *finite number* of smooth occupied modes is a smooth CAR-compatible perturbation of an *already known Hadamard* reference, provided the chosen occupation projector still satisfies positivity/orthogonality. This can pay *relative* thermal/occupation/quantum-channel stress variations once the reference state and physical modes are fixed.

**When a three-plasma drive changes `A` or `g`:** the Dirac operator, microlocal transport, comparison Hilbert space and local Hadamard parametrix change. **Do not** subtract two kernels in unmatched trivializations and call the result smooth. We require a specifically constructed Møller/relative-Cauchy-evolution map (and a correct charged spinor bundle identification), local finite-counterterm matching, induced `δJ`, `δ<T>`, gauge/diffeomorphism Ward consistency and physical causal in-in response. No source-free phase/difference argument proves dynamical exotic stress.

The static return-loop Wilson parameter is an independent gauge-invariant global datum on a noncontractible S1; the *physical* fermion boundary parameter combines spin s and gauge α_W. Gauge changes of a local connection on an OPEN path can alter the transport's endpoint phase without changing a closed loop's holonomy. A sourced change of α_W on the CLOSED handle can change the Casimir state, but the quantitative curved 4D stress must be derived, not assigned the 1+1D Bernoulli formula.
