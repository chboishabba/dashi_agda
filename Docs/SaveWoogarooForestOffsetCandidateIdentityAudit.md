# Save Woogaroo Forest — offset candidate identity / prior-protection audit

This note is for Save Woogaroo Forest and assisting/pro-bono lawyers. It is not legal advice. It addresses a specific source-diligence risk: the same place/property name can appear in multiple restoration, conservation and EPBC-offset contexts without proving that the underlying cadastral land is the same.

## 1. What the 2019/8575 submission actually says

A public submission responding to EPBC 2019/8575 says the proposed offset package offers three properties:

- **Avonvale — 168 ha — RE 12.11.14**;
- **Esk — 280 ha — RE 12.9/10.2**;
- **Mt Walker West — 225 ha — RE 12.8.16**.

The same submission characterises those properties as grazed/bare paddocks requiring planting and criticises their ability to replace mature Woogaroo habitat.

These are **secondary submission propositions**. They are useful acquisition leads but are not agency findings and are not a substitute for the proponent's final offset plan.

## 2. Avonvale is a name collision, not yet a parcel identity

Publicly available material from other projects also uses the name **Avonvale**.

A separate Avonvale/Cherry Gully Offset Management Plan for another EPBC action describes relevant vegetation including sparse juvenile/non-remnant vegetation and associates pre-clear vegetation in parts of that site with **RE 12.9-10.7**.

A separate approval requires a minimum of **183 ha** within the Avonvale and Cherry Gully Offset Area to be legally secured for another action.

Greenfleet also identifies an **Avonvale** property as one of the properties within its Ivory Creek restoration project, with revegetation/restoration works underway.

None of these sources currently gives us the bridge:

```text
this public Avonvale polygon
  =
the 168 ha Avonvale proposed for EPBC 2019/8575
```

Therefore they must not be merged.

## 3. Why the collision is legally useful anyway

It creates a concrete due-diligence question for the 2019/8575 offset package:

> **What exact lot/plan and polygon is the proposed 168 ha Avonvale offset, and does any part overlap land already legally secured, restoration-funded, committed to another EPBC offset, or otherwise protected?**

If the answer is **no overlap**, the other Avonvale material is simply background and should drop out.

If the answer is **overlap**, counsel/ecologists should then test:

- whether the same hectare is being counted twice;
- whether the earlier legal security already reduces the without-offset risk of loss;
- whether existing restoration commitments are being counted as new/additional gain;
- whether different offsets use distinct protected-matter attributes or genuinely compete for the same ecological uplift;
- whether stacking is expressly permitted and transparently accounted for.

But until exact geometry is paid:

```text
prior Avonvale offset nearby
  !=
double counting
```

and:

```text
Greenfleet restoration at Avonvale
  !=
2019/8575 gain already funded
```

## 4. The regional-ecosystem mismatch is a clue, not a conclusion

The submission's 2019/8575 Avonvale entry refers to **RE 12.11.14**. The other public Avonvale offset plan discusses **RE 12.9-10.7** for relevant vegetation/pre-clear mapping.

That difference could mean:

- different Avonvale parcels;
- different portions of a larger property;
- different mapped vegetation communities within the same property;
- different mapping dates/methods;
- or an error in one source.

So:

```text
RE mismatch
  !=
parcel mismatch proved
```

but it is a strong reason to require cadastral/polygon identity before relying on any Avonvale comparison.

## 5. Mt Mort / Mt Walker West has the same attribution problem

A 2019/8575 submission names a proposed **Mt Walker West** offset. Separately, Ipswich's Koala Conservation Plan describes the broader **Mt Mort** priority rehabilitation landscape as highly rural, with substantial land already under voluntary conservation agreements/Land for Wildlife and a large QTFN conservation property.

Those official regional facts are relevant to the question of additionality/risk of loss, but they cannot be applied to the exact proposed offset parcel until its polygon is known.

Likewise:

```text
Mt Walker West / Mt Mort submission lead
  !=
Aroona Station
```

unless a primary project source proves the identity.

## 6. Immediate acquisition fields

For each proposed offset candidate, obtain:

```text
candidate name
lot/plan
GIS polygon
owner/tenure
regional ecosystem polygons
remnant/regrowth/non-remnant status
existing covenants / voluntary declarations
Land for Wildlife / VCA status
prior EPBC offset commitments
restoration grants or funded works
current zoning and lawful clearing pathway
without-offset risk-of-loss assumption
with-offset legal security
```

For Avonvale specifically, compare the exact polygon against:

1. Avonvale/Cherry Gully polygons used by other EPBC approvals;
2. Greenfleet/Ivory Creek restoration polygons;
3. existing VMA voluntary declarations/covenants;
4. any other publicly registered environmental-offset areas.

## 7. Current attribution state

```text
2019/8575 offers Avonvale/Esk/Mt Walker West = SECONDARY SUBMISSION CLAIM
areas / RE codes for those candidates = SECONDARY SUBMISSION CLAIM
other Avonvale offset plans = PRIMARY/EXTERNAL SOURCE FOR OTHER PROJECTS
Greenfleet Avonvale restoration = PRIMARY/EXTERNAL SOURCE FOR GREENFLEET PROJECT
same Avonvale parcel = NOT PROVED
polygon overlap = NOT PROVED
prior protection overlap = NOT PROVED
double counting = NOT PROVED
offset inadequacy = NOT PROVED
```

The strongest use of the public material is therefore not to accuse the proponent of double counting. It is to give counsel a precise **identity/additionality discovery request** before accepting any claimed Avonvale conservation gain.
