## Immediate bandwidth arithmetic

Decimal line speed 1 Gbit/s = 125,000,000 B/s, 10 Gbit/s = 1,250,000,000 B/s. Serialization for S bytes is 8 S / (1e9 or 1e10) seconds. No Ethernet/TCP/AEAD headers or contention.

- 384 FP32 coordinates = 1,536 B: 12.288 / 1.2288 microseconds.
- 4,096 x 384 FP32 coordinates = 6,291,456 B: 50.331648 / 5.0331648 milliseconds.
- 1 MiB: 8.388608 / 0.8388608 ms.
- 16 MiB: 134.217728 / 13.4217728 ms.
- 64 MiB: 536.870912 / 53.6870912 ms.

Remote expert request+response one 384D vector each -> 3,072 B:
24.576 microseconds on 1 Gb/s or 2.4576 microseconds on 10 Gb/s, plus one RTT, queueing, network+cryptographic overhead and remote compute. At 5 ms RTT, compression rarely helps an isolated tiny token request as much as batching, local reuse or colocating experts.

For an estimated packet ratio r = uncompressed bytes / compressed complete-wire bytes, serialization savings on S original bytes is
  deltaT = S * (1 - 1/r) / linkBytesPerSecond.
Compression wins only when deltaT exceeds codec CPU/GPU time + additional handshakes/coordination and any bytes for state version, residual, correction or witness. At 1 Gb/s, saving 1 MiB buys 8.39 ms; at 10 Gb/s only 0.839 ms. Do NOT pretend this is an executed network benchmark.

## Five-strategy Pareto decision

A Local: zero activation WAN bytes, local expert work and possible model residency.
B Remote ordinary: input + output + route/commit metadata, RTT paid.
C Remote exact self-contained codec: same consumer computation plus actual full framed bytes, encode/decode cost and RTT.
D Remote acknowledged history/delta: prior-state version, signed correction and ACK/replay cost; requires remote agreement and fallback.
E Reused symbolic/geometric expert action: retain learned expert identity, action witness, proof of commuting consumer or exact tensor restoration and any residual. This MAY remove transport if the consumer is already local and admits the action, but cannot be inferred from matching chart sizes.

Compare p50/p95/p99 and throughput separately from one-way serialization, per-packet side cost, state synchronisation and token quality. DeepSeek-V3/Kimi K3 are learned-MoE reference architectures, not semantic antagonism proofs.

## BIDI proof gates

1. Record semantic intervention a, latent geometric action g, decoder d and actual factorisation f=d∘h as distinct types.
2. Prove the relevant square h(a⋅x)=g⋅h(x) and decoder compatibility d(g⋅z)=a⋅d(z) for chosen consumer, OR ship exact residual and reopen original input/state.
3. Require signed history and expert chart version to survive routing; check that top-k, weights and state transition respect the action, or retain correction.
4. For remote inference, include authority, authenticated sequence/session, peer state ACK, layout and size proof, decoder hash and admissible downstream consumer; SHA-256 alone does not authenticate.
5. Reject conflations among geometric antipodes, argument objections and observed safety/harmfulness. Preserve original authorship and separate source-written, checked, measured and formally kernel-certified results.
