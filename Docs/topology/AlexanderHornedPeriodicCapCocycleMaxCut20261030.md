## 3. Why this is a genuine all-conjugator G4 obstruction

Define \`psi=Inn(q^-1)∘phi\`. Since \`phi(w)=q w q^-1\`,
\`psi(w)=w\`; however the automorphism composition has

\`\`\`text
psi^3 = Inn((phi^2(q) phi(q) q)^-1) = Inn(w).
\`\`\`

In particular \`psi^3(a)=w a w^-1 != a\`.
The Agda source checks all three generators under \`psi^3\`
and explicitly refutes strict order three on \`a\` by normal form.

This is NOT fixed by another basing conjugator. Let \`q'\`
also satisfy \`phi(w)=q' w (q')^-1\`.
Then \`q^-1 q'\` centralizes \`w\`. Since \`w\` is cyclically
reduced and has **exactly one positive a occurrence**, it
cannot be a proper free-group power: a cyclically reduced
\`n\`-th power, \`n>=2\`, has each cyclic letter count divisible
by \`n\`. By the classical free-group centralizer theorem,
\`q'=q w^k\` for some integer \`k\`.

A direct group calculation now gives

\`\`\`text
T(q') = phi^2(q') phi(q') q' = w^(3k-1)
psi_(q')^3 = Inn(w^(1-3k)).
\`\`\`

For **every integer** \`k\`, the exponent \`1-3k\`
is nonzero. The free group has trivial centre, hence the
last inner automorphism cannot be identity. Thus:

> The PARTICULAR nonlinear \`phi\` admits no **strict
> order-three inner re-basing** which simultaneously fixes
> the selected based parent meridian \`w\`.

The actual mathematical argument uses centralizers and integer
arithmetic, not the finite regression alone. The Python script

This is a boundary-twist / central extension obstruction to
lifting an order-three OUTER/peripheral-conjugacy-class action
as a strictly periodic BASED action. It is not a statement that
\`phi\` itself fails order three; \`phi^3=id\` really holds.
It also does not rule out a nonperiodic cap-relative
mapping-class representative or an action on conjugacy classes
or a coherent **groupoid** with nontrivial 2-cell/twist.

## 4. Separate Newman open-cap periodicity obstruction

Let \`H\` be a connected compact genus-three handlebody with
connected boundary \`∂H\`. Let \`h:H→H\` be a finite-order
homeomorphism fixing a nonempty **relatively open boundary disk
pointwise**, and assume the boundary maps to itself (automatic
for a homeomorphism of a manifold with boundary).

Restriction \`h|∂H\` is periodic on the connected closed
surface \`∂H\` and fixes a nonempty open set. By Newman's
classical periodic transformation theorem, \`h|∂H=id\`.

The standard surjection
\`π1(∂H,x0)→π1(H,x0)\` (for a basepoint \`x0\` inside
the fixed cap) implies \`h_*=id\` on handlebody \`π1\`.
So **no nontrivial Nielsen action** can be realised
by such a finite-order, pointwise-open-cap-fixed handlebody
homeomorphism. This proof is a paper consequence of Newman
plus the standard handlebody \`π1\` surjection, NOT a 3D
topology theorem formalized in the source Agda kernel.

**Scope limits:** This does not forbid (i) infinite-order
cap-relative supported handle slides; (ii) a finite-order action
preserving a cap SETWISE but not pointwise; (iii) the already
separate external root-sector C3, whose fixed-point/cap
hypotheses are different; (iv) periodic actions on unrelated
spaces or different boundary components.
