# No-promotion boundary

This tranche may not be summarized as a proof of Gödel incompleteness or as a certified diagonal lemma unless the corresponding theorem and exact-head certification receipts exist.

In particular:

- exact syntax serialization != internal arithmetic representability;
- total Nat decoding != primitive-recursive decoding;
- historical Gödel substitution PR != custom base-12 substitution PR;
- source citation != theorem inhabitant;
- validation command != successful validation run;
- diagonal lemma != Gödel I/II without the additional proof/provability/consistency hypotheses.
