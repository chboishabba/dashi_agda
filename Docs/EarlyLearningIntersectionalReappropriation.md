# Early learning: intersectional capability, eKindy and re-appropriation resistance

## Why this tranche exists

The earlier early-learning choice bridge proved two structural facts:

1. the same public choice menu need not determine the same situated opportunity;
2. the same `expanded choice` label can describe either an additional family route or substitution away from professional capacity.

This tranche asks the next question: **what has to remain visible once `family` itself is treated intersectionally, and how can a constructive home-learning pathway resist political re-appropriation into parental-sovereignty / institutional-exit architecture?**

The answer is not `professional > family` and not `parent knows best`.  The carrier is multi-actor and authority is coordinate-specific.

## 1. Family is not one policy subject

`EarlyLearningIntersectionalCapabilityExact` keeps separate coordinates for:

- child;
- caregiver;
- household;
- place;
- labour/time position;
- disability/access needs;
- culture/language;
- gendered care burden;
- kin/community authority;
- institutional relation/trust.

A finite witness again maps two distinct situated positions to the same public `sameFormalFamilyChoice` label while retaining different effective-capability observations.  Therefore:

```text
familyChoiceCannotDetermineEffectiveCapability
```

The Bool observation is a structural witness only.  It is not an empirical claim that one named demographic has lower developmental opportunity.

The point is carrier-level: once a policy collapses these coordinates into `family choice`, no reweighting inside that scalar can reconstruct what was erased.

## 2. Family agency is not parental sovereignty

The new authority carrier distinguishes:

```text
child preference
family context
kin/community authority
professional pedagogy
public safeguarding
public entitlement
```

and assigns different canonical holders to different domains.

The explicit boundary is:

```text
parentalSovereigntyOverEveryDomain = false
```

This is especially important for Aboriginal and Torres Strait Islander policy.  Community-controlled authority is not a synonym for nuclear parental authority.  The source registry therefore includes:

- *Bringing them Home* (1997), with its self-determination boundary;
- the National Aboriginal and Torres Strait Islander Early Childhood Strategy / SNAICC shared-decision-making context;
- Queensland Kindy Uplift as an operational example of differentiated, culturally safe and inclusion-sensitive capability support.

Institutional history also does not prove that every contemporary professional or service is unsafe.  The point is that institutional relation and community authority cannot be erased from the policy carrier.

## 3. Equity is partly topological

The formalism does not define equity as `same cheque + larger amount`.

Different positions may require different support kinds:

```text
remote -> connectivity + teacher contact
regional -> transport + teacher contact
specialist need -> specialist + accessibility support
multilingual/community-language -> multilingual + cultural-governance support
```

This is deliberately schematic, but it captures the key structural claim:

```text
equity may require different connections, not only more scalar transfer.
```

## 4. eKindy as the constructive witness

`EKindyRelationalCommonsExact` formalises an eKindy-like topology:

```text
qualified teacher relation
+ family/tutor relation
+ common learning framework
+ local contextualisation
+ synchronous review
+ evidence return
+ optional nudge layer
```

and explicitly records:

```text
nudgeIsPrimaryCareRelation = false
```

The harvesting example is represented as a contextualised activity: the common learning aim is retained while local family life changes the activity through which that aim is enacted.

That gives a stronger meaning of personalisation:

```text
common curriculum x local lifeworld -> situated learning
```

rather than:

```text
administrative category -> generic personalised message.
```

The public pedagogical commons is route-neutral.  Centre users, home users and kin carers can all receive resources, and access does not require leaving professional provision.

## 5. Nudge is a peripheral protocol, not the service

The module imports the existing `PedagogicalJPlusOneRouting` boundary unchanged.

The existing theorem that blocks `nudgeEqualsCareRoute` remains authoritative.  Contextual fit, human interpretation, participant choice, opt-out and evidence return remain required.

So the architecture is:

```text
relational/professional loop
  -> context-sensitive resource routing
  -> optional low-burden nudge
  -> evidence return / revision
```

not:

```text
classify family -> send SMS -> declare support delivered.
```

This also preserves the OEF/AI result that classification is a proxy that routes attention rather than student/family meaning or pedagogical authority.

## 6. Conservative re-appropriation is a frame problem, not an atom problem

`EarlyLearningReappropriationBoundaryExact` separates:

- `PolicyAtom`;
- `PolicyFrame`;
- `InfluenceEvidenceClass`;
- actor kind;
- expert endorsement scope.

A family-care payment can appear in both:

```text
situated-capability / retained-entitlement architecture
```

and:

```text
institutional-exit architecture.
```

The atom is therefore not sufficient to identify its political trajectory.

The source registry grounds the political-history side with:

- Heath Brown, *Homeschooling the Right: How Conservative Education Activism Erodes the State* (2021), DOI `10.7312/brow18880`;
- Carla Tomazini, *Sacred Families, Dangerous Schools: Transnational Homeschooling Advocacy and Anti-Gender Politics in Brazil* (2026), DOI `10.1093/sp/jxag045`;
- Kristina Stoeckl, *Traditional values, family, homeschooling...* (2023), DOI `10.1093/icon/moad026`.

These sources establish that conservative homeschooling can participate in state-substitution and transnational moral-conservative / anti-gender political networks.  They do **not** establish that every homeschooler, religious family, Liberal voter or Australian family-choice proposal belongs to one coordinated project.

The following promotions are therefore impossible in the formal carrier:

```text
shared frame -> proven coordination
political provenance -> proven private motive
conservative/religious context -> proven vote
```

## 7. Re-appropriation resistance gate

The constructive gate requires all of the following coordinates to remain true:

```text
professional floor retained
qualified relationship retained
child public entitlement retained
family route additional, not substitutionary
support varies by situated need
resources do not replace relationship
nudges remain optional/contextual
public safeguarding retained
curriculum exit is not automatic
plural authority retained
public commons not conditional on exit
```

This is the formal version of:

> pluralise where learning happens without privatising who carries responsibility for the child's educational entitlement.

Intersectionally, the stronger form is:

> pluralise pathways and redistribute capability while refusing to collapse child, family, kin/community, professional and public authority into a single actor.

## 8. Cash, services and early investment remain separate evidence fibres

The registry includes Michael Forster and Gerlinde Verbist, *Money or Kindergarten?* (OECD, 2012), DOI `10.1787/5k92vxbgpmnt-en`.

Its role is to prevent the cash/service distinction from being treated as a purely ideological preference: cash and in-kind services have empirically different distributive profiles.  The formalism does not promote that cross-country result into a universal theorem that services dominate every Australian design.

It also records Jorge Luis Garcia, James J. Heckman, Duncan Ermini Leaf and Maria Jose Prados, *The Life-cycle Benefits of an Influential Early Childhood Program*, NBER Working Paper 22993, DOI `10.3386/w22993`.

The 13.7 percent annual return / 7.3 benefit-cost result is retained as programme-specific evidence, not as a universal multiplier for ECEC expenditure.

## 9. Co-production rather than consultation theatre

The registry includes Monforte, Netherway and Smith, *The world cafe is an unmethod within co-produced research* (2023), DOI `10.1080/14780887.2023.2239728`.

World Cafe can therefore appear as a legitimate participatory knowledge-production method, but participation alone does not prove representative inclusion or constitutive authority.

Brown/Kimber remains the stronger authority boundary: being asked for feedback does not automatically grant authority over the question, projection, carrier, consumer or dynamics.  Conversely, an expert asked to endorse a pre-framed policy need not accept that framing as the correct problem definition.

## 10. Endorsement as a governed policy event

`ExpertEndorsementReceipt` makes endorsement itself first-class.

A safe endorsement carries:

- the specific atom endorsed;
- the endorsement scope;
- the architectural conditions;
- the re-appropriation resistance gate;
- an explicit statement that endorsement of the atom is not endorsement of the whole programme.

The intended political strategy is therefore neither blanket endorsement nor blanket refusal:

```text
extract useful atom
-> rebuild it inside a situated-capability architecture
-> attach conditions to public endorsement
-> make those conditions travel with quotation/use.
```

This allows a genuine family-learning idea to be advanced without supplying a detachable `expert supports parental choice` authority token.

## Aggregate

`DASHI.EverythingEarlyLearningIntersectionalReappropriation` imports the previous early-learning PNF bridge, the new sources, intersectional capability carrier, eKindy relational commons, re-appropriation boundary, OEF/AI, J+1 nudge routing, student-identified supports, Brown/Kimber governance and policy-relative projection safety.

## Compact result

```text
family choice
!= situated capability

family agency
!= parental sovereignty

home delivery
!= institutional exit

cash support
!= professional entitlement

resources
!= relational pedagogy

nudge
!= care

shared political frame
!= proven coordination

expert support for one atom
!= endorsement of the whole programme
```

The formal target is not to make the policy apolitical.  It is to make its political and distributive commitments explicit enough that a useful family-learning pathway cannot silently mutate into deprofessionalisation, universal-voucher formal equality, anti-inclusive curriculum exit, or borrowed expert legitimacy.
