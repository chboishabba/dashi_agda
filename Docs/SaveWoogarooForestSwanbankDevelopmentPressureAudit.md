# Save Woogaroo Forest — Swanbank data-centre development-pressure audit

This note is for Save Woogaroo Forest and assisting/pro-bono lawyers. It is not legal advice. It records a fresh, nearby Ipswich development-pressure example and keeps its relevance to Woogaroo strictly bounded by attribution and same-object discipline.

## What the current public record supports

Ipswich City Council Development.i currently records application **12285/2026/MCU** as a Material Change of Use for a warehouse/data centre at **Lot 5 Six Leaf Street, Swanbank**. The application is under **Code assessment**, is still in progress, and the Council record states **Public Notification Required: No**.

The proposal is publicly described as a roughly **10-storey / 72 m / 82,000+ m²** data centre. Council application documents also include an ecological assessment and identify a State referral issue associated with mapped vegetation / koala habitat.

The same property history records:

- **9000/2026/SPSR** — superseded planning scheme request for a data centre, decided in June 2026;
- **13857/2025/OW** — earthworks and associated vegetation clearing;
- **11711/2023/CA** — battery-energy-storage development.

These are primary Council-record propositions. News reports and campaign material can describe or criticise the process, but they are not substitutes for the Council record.

## Correction to the initial recollection

The 10-storey data-centre proposal is in **Swanbank**, not White Rock.

White Rock remains relevant only as a separate landscape/proximity question because Swanbank, Blackstone, White Rock, Ripley and Springfield form part of the same broader south-Ipswich growth landscape. Historic/state planning maps show White Rock Conservation Park / White Rock-Spring Mountain Conservation Estate in that broader geography.

Therefore:

```text
Swanbank data-centre site != White Rock
```

and:

```text
same broader landscape != same parcel / same statutory consumer
```

Exact distance, corridor connection and protected-area relationship should be spatially measured before being used as a project-specific proposition.

## Why this matters to Woogaroo

The relevance is **development-pressure and planning-process context**, not merits transfer.

The Swanbank example shows that, within the same LGA and broader growth landscape:

- large projects can be proposed on land with mapped koala-habitat issues;
- existing industrial/energy infrastructure can increase development pressure;
- a Code-assessable pathway can mean no statutory public notification;
- superseded-planning-scheme requests can materially affect the assessment pathway;
- vegetation clearing can sit within a sequence of prior and current approvals rather than one isolated application.

That is relevant to the Woogaroo offset counterfactual because the Commonwealth offset framework requires a defensible **without-offset risk of loss**. Fresh nearby development activity is evidence that urban/development pressure in Ipswich is real, but it does not itself quantify the probability that any particular Woogaroo or offset parcel would be cleared.

## Key WrongType boundaries

```text
Code assessment != unlawful assessment
No public notification != no regulatory assessment
Mapped koala habitat != automatic refusal
Swanbank pressure != Woogaroo parcel pressure proved
Same LGA != same planning instrument
Superseded scheme at Swanbank != Springview exemption/grandfathering proved
News criticism != Council/State finding
```

## New counsel questions

1. What exactly allowed the Swanbank data centre to be Code assessable and avoid public notification, and what role did **9000/2026/SPSR** play?
2. Does the Swanbank sequence reveal any planning-law mechanism relevant to the **Springview exemption/grandfathering audit**, or are the statutory instruments materially different?
3. Can nearby current approvals and land-value/development trends be used as objective evidence when testing a proponent's **risk-of-loss** assumptions for a Woogaroo impact parcel or a proposed offset parcel?
4. Where an offset parcel is rural, already protected or under conservation management, what evidence is required before assigning it a high without-offset probability of loss?
5. Does the exact Swanbank parcel intersect State koala habitat mapping, and what State referral outcome follows? Keep the State referral separate from Council Code assessment.
6. What is the exact spatial relationship between the Swanbank site and White Rock-Spring Mountain Conservation Estate / the broader Flinders-Karawatha network?

## Current legal use

The strongest bounded use is:

```text
fresh nearby development application
+
koala-habitat regulatory issue
+
no-notification Code pathway
+
existing industrial/energy pressure
  ->
credible evidence that development pressure in the broader Ipswich landscape is non-theoretical
```

but not:

```text
Swanbank development
  ->
Woogaroo must be refused
```

or:

```text
Swanbank development
  ->
exact Woogaroo risk-of-loss percentage
```

The next useful comparison is to place the Swanbank, Springview/Woogaroo and candidate offset parcels on the same planning-pressure matrix: zoning, current applications, historical clearing, existing protection, lawful clearing pathway and surrounding infrastructure.
